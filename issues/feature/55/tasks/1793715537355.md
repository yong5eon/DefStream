# 재시도 API 인자 이름 변경

사용자 요청에 따라 공개 API 인자명을 `max_retries`에서 `retry`로, `retry_interval`에서 `interval`로 변경했다. `emit()`·`request()` 구현, 단위 테스트, 한국어·영어 작업 매뉴얼, 요구사항·계획·구현 요약과 고객용 변경 로그를 새 이름에 맞췄다. 재시도 횟수와 기본값·입력 검증 동작은 변경하지 않았다.

`tests.test_task_messages` focused suite를 다시 실행해 13개 테스트가 통과함을 확인했다. Pylance에서 두 공개 함수의 호출부 호환성을 확인했고 `Message.py` 진단은 없으며 syntax 검사도 통과했다. 저장소에서 기존 인자명 문자열을 검색했을 때 일치 항목은 없었다.
