# PR 리뷰 경계값 회귀 검증

수정 전 `tests.test_task_messages.MessageTests.test_interval_above_timeout_max_is_rejected_before_broker_calls`를 실행하여 두 API에서 `10**400`은 `OverflowError`, `1e100`과 `TIMEOUT_MAX + 1`은 사전 거부 누락으로 실패하는 것을 확인했다.

수정 후 workspace Python에서 `DefStream.__path__`의 첫 경로를 `src`로 지정한 기존 unittest 실행 방식으로 `tests.test_task_messages`를 실행했다. 15개 테스트가 통과했다. 두 API에서 범위 밖 값은 브로커 호출·대기 없이 거부되고, 0과 `TIMEOUT_MAX` 경계는 허용되어 Mock 대기에 그대로 전달됨을 확인했다. 실제 장시간 대기는 수행하지 않았다.

Pylance의 `Message.py` 진단은 없고, 변경 테스트의 syntax 검사도 통과했다. 실제 브로커 통합 테스트는 실행하지 않았다.

[앞선 인자명 변경 기록](./1793715537355.md)의 “기존 인자명 검색 결과 없음”은 당시 코드·현행 매뉴얼 대상 결과로 한정해 읽어야 한다. 변경 전 이름을 보존한 기록 자체까지 포함한 저장소 전체 결과를 뜻하지 않는다.
