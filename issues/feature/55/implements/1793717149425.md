# 재시도 간격 오버플로 사전 차단

[PR #61 리뷰](https://github.com/yong5eon/DefStream/pull/61#discussion_r4456061735)와 [대기 오버플로 지적](https://github.com/yong5eon/DefStream/pull/61#discussion_r4456061789)에 따라 [Message.py](../../../../src/Worker/Message.py)의 간격 검증만 보완했다.

`interval`은 플랫폼별 `threading.TIMEOUT_MAX`초 이하로 제한한다. `isfinite()`보다 먼저 범위를 비교하여 `10**400` 같은 정수의 실수 변환 오버플로도 피한다. 범위 밖 값은 브로커 호출 전에 `ValueError`로 거부하며, 재시도 루프·공개 시그니처·기본값은 유지한다.

한국어·영어 매뉴얼과 요구사항·변경 로그에 상한을 반영했다. 이슈 원문과 기존 단계별 기록은 변경하지 않았다. 검증 결과는 [작업 기록](../tasks/1793717149426.md)에 정리했다.
