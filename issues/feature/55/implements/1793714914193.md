# Worker 메시지 발행·요청 재시도 구현

[Worker 메시지 함수](../../../../src/Worker/Message.py)의 `emit()`·`request()`에 키워드 인자 `retry`와 `interval`을 추가했다. 기본값은 각각 `None`과 1초이며, 재시도 횟수는 최초 호출 이후의 추가 시도 수로 해석한다. 횟수는 `None` 또는 bool이 아닌 0 이상의 정수, 간격은 bool이 아닌 유한한 0 이상의 숫자만 허용하고 브로커 메서드 호출 전에 검증한다.

공통 내부 호출 경로는 브로커의 실제 `emit()` 또는 `request()` 예외만 재시도한다. 입력·작업·지원 기능 검증은 반복하지 않는다. 다음 시도가 남은 실패에만 `sleep()`을 적용하고, 성공값과 최종 예외 객체를 그대로 반환·전파한다. `request()`의 `timeout` 및 우선순위 인자는 각 시도에 유지된다. 사용자 결정대로 `RemoteError`를 포함한 일반 예외를 모두 재시도하므로 요청·작업이 중복될 수 있다.

[메시지 API 테스트](../../../../tests/test_task_messages.py)에 Mock 브로커와 Mock 대기를 사용하는 검증을 추가했다. `emit()`과 `request()`의 13개 focused 테스트가 통과했으며, 실제 브로커 연결 검증은 수행하지 않았다. API 사용법과 중복 실행 주의사항은 한국어·영어 [작업 매뉴얼](../../../../docs/Tasks.md), [영문 작업 매뉴얼](../../../../docs/Tasks.en.md)과 [변경 로그](../CHANGELOG.md)에 반영했다.
