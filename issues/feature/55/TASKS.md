# 작업 종합

## 결과

이슈 #55의 요구를 현재 Worker API, Broker Protocol, 메시지 테스트와 작업 매뉴얼에 대조해 분석했다. `emit()`·`request()` 호출에만 재시도를 적용하고 입력 검증·지원 기능 확인은 재시도 바깥에 두는 방향을 정리했다.

사용자 선택에 따라 브로커 호출에서 발생하는 모든 예외를 재시도하며 `RemoteError`도 포함한다. 따라서 재시도 도중 동일 작업이나 요청이 반복될 수 있다는 제한과 문서 반영 필요성을 명시했다.
