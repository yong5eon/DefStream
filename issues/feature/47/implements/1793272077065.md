# 정수 밀리초 입력과 생성 시 정규화

사용자가 `timeout`에 정수 밀리초와 `timedelta`를 함께 받는 방안에 동의하여 기존 구현을 확장했습니다.

- [Subscription](../../../../src/Broker/Implements/RabbitMQ/Subscription.py)은 `Optional[Union[int, timedelta]]`를 받고 `timedelta` 입력을 생성 시 정수 밀리초로 정규화합니다. `None`은 유지하고 `bool`은 명시적으로 거부합니다.
- [Connection](../../../../src/Broker/Implements/RabbitMQ/Connection.py)의 `declare()`에서는 추가 변환 없이 정규화된 값을 큐 인자로 전달합니다.
- 정수·기간 입력의 정규화·선언 결과, Mapping 원본 보존 및 잘못된 정수 입력 테스트를 보완했습니다.
- 요구사항·계획·종합 결과·변경 로그와 한국어·영어 매뉴얼에 정수 단위 및 생성 후 속성 계약을 반영했습니다.

기존 큐 변경이나 ACK 계약 변경은 없습니다. [이전 구현 기록](./1793271568985.md)의 `timedelta` 전용 입력·선언 시 변환 설명은 이 기록으로 대체하며, 검증 결과는 [재검증 기록](../tasks/1793272077066.md)에 정리합니다.
