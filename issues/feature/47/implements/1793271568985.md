# Subscription timeout의 큐 선언 전달

- [Subscription](../../../../src/Broker/Implements/RabbitMQ/Subscription.py)의 마지막 필드에 `timeout: Optional[timedelta] = None`을 추가하여 기존 위치 인자 순서를 유지했습니다.
- 구독 생성 시 타입·양수·정수 밀리초 정밀도를 검증합니다. 부적합한 입력은 오류로 드러내며 변환을 위한 자동 절삭이나 폴백을 하지 않습니다.
- [Connection.declare](../../../../src/Broker/Implements/RabbitMQ/Connection.py)는 timeout이 있을 때만 `timedelta` 정수 나눗셈으로 밀리초를 계산하여 작업 큐의 `x-consumer-timeout`에 전달합니다. 기존 DLQ·우선순위 인자와 함께 구성하며 오류 큐에는 전달하지 않습니다.
- [timeout 테스트](../../../../tests/test_rabbitmq_timeouts.py)에 객체·Mapping·Worker 선언, 생략·`None`, 위치 인자 호환, DLQ·우선순위 병합, 경계값·큰 값 정밀도, I/O 전 오류, 소비 등록·RPC 대기시간 독립성과 선언 오류 전파를 추가했습니다.
- 한국어·영어 [RabbitMQ 매뉴얼](../../../../docs/RabbitMQ.md)에 최종 API와 선언 방법을 반영했습니다. 선택 설정의 상세 설명이므로 최소 빠른 시작을 담은 루트 README는 유지하며 별도 다이어그램은 추가하지 않았습니다.
- Consumer·Worker·Redis 및 기존 큐의 운영 설정은 변경하지 않았습니다.

새 테스트의 구현 전 실패와 구현 후 통과를 확인했으며, 관련 회귀 검증은 진행 중입니다. 상세 결과는 후속 작업 기록에 정리합니다.
