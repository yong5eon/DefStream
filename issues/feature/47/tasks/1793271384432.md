# timeout 설정 전달로 작업 범위 한정

사용자가 이번 작업은 `Subscription`의 timeout을 `declare()`에서 적용하는 기능이며 기존 큐 변경 등은 운영 측 책임이라고 명확히 했습니다.

- [요구사항 명세](../REQUIREMENTS.md)에서 추가 사용자 확정을 요구하던 내용을 제거했습니다.
- 이슈 예시의 `timeout`·`Optional[timedelta]`를 구현 기준으로 정리하고, 변환·입력 검증은 구현 세부사항으로 구분했습니다.
- 기존 큐의 변경·반영 확인, 운영 절차 및 실제 만료 실측을 이번 작업의 구현·완료 검증 범위에서 제외했습니다.
- 앞선 [명세 작성 기록](./1793271236067.md)의 미확정 상태는 이 기록과 현재 명세로 대체합니다. 제품 코드나 운영 환경은 변경하지 않았습니다.
