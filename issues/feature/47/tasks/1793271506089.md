# 구현 계획과 기존 동작 확인

- 실제 브랜치 `feature/47`와 깨끗한 작업 트리를 확인했습니다. 기존 문서는 커밋된 상태이며 [최신 범위 정리](./1793271384432.md)를 기준으로 재개했습니다.
- [작업 계획](../PLAN.md)을 작성했습니다. `timeout`은 양수의 정수 밀리초 정밀도 `timedelta`로 검증하고, 부동소수점 없이 큐 선언 인자로 변환하기로 했습니다.
- 저장소 루트에서 기존 환경의 `python -m unittest discover -s tests -p test_rabbitmq_worker.py`를 실행하여 10개 통과했습니다.
- 같은 환경에서 `python -m unittest discover -s tests -p test_rabbitmq_priorities.py`를 실행하여 9개 중 8개 통과, 브로커 연동 1개 생략했습니다.
- Pylance 참조 조회와 소스를 통해 RabbitMQ 내부의 구독 파싱·선언 경로를 확인했습니다. 공통 Worker와 Redis는 변경하지 않습니다.
- 적용 지침은 `instructions/CODE.instructions.md`의 영어 진단 문구 정책, `instructions/DOCS.instructions.md`의 한국어·영어 매뉴얼 동기화 및 공통 Python·Markdown 지침입니다.
