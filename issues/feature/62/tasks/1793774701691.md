# Connection 기반 타이머로 범위 한정

- 사용자 지시에 따라 이번 범위를 Connection을 이용하는 `SetTimer`, `Timer`, `TimerCallback`과 RabbitMQ 연결 지원 및 직접 관련된 테스트·문서로 한정했다.
- [앞선 분석 기록](./1793772101827.md)에서 확정했던 Consumer의 메서드 제거·close 추상 메서드 선언은 후속 리팩터링으로 분리했다. 이전 기록은 당시 결정으로 보존하며 현재 범위는 [요구사항 명세](../REQUIREMENTS.md)를 따른다.
- Consumer·Worker·Ping·Pool·Executor·Event 및 Redis 구현을 변경 대상으로 삼지 않는다. 관련 호출 경계 재설계도 이번 선행 조건에서 제거했다.
- 연결 단위 예약에 Consumer 종료 연동을 추가하지 않음을 명시했다. 원문의 소비 종료 정리와 차이를 구분하고 연결 종료·오류 시 핸들 처리는 구체화할 사항으로 남겼다.
- 제품 코드는 변경하지 않았으며 제품 테스트도 실행하지 않았다. 구현 전 미확정 사항 확인과 계획 작성이 남아 있다.

## 검증

- PowerShell 검사로 이슈 문서 5개의 최상위 제목·상대 링크·로컬 절대 경로 미포함을 확인했다.
- `gh issue view 62 -R yong5eon/DefStream --json body`로 조회한 원문과 README의 원문 구역이 줄바꿈·끝 공백 정규화 후 일치했다.
- 저장소 루트에서 `git diff --check`가 통과했다. `git status --short`에서 변경이 이 이슈 문서에만 있음을 확인했고, 실제 브랜치는 `feature/62`이다.
