# 타이머 등록 시그니처 확정

- 사용자 제시 계약을 [요구사항 R2](../REQUIREMENTS.md#r2-타이머-핸들과-콜백)에 반영했다.
- `set_timer(self, cb: TimerCallback, seconds: int) -> Timer`로 이름·인자 순서·타입·반환 타입을 확정했다. 두 인자는 기본값 없이 위치 또는 키워드로 전달한다.
- `Timer`, `SetTimer`에 `@runtime_checkable`, 각각 `remove`, `set_timer`에 `@abstractmethod`를 적용하는 계약을 명세했다. `TimerCallback.__call__() -> None`도 그대로 유지했다.
- 제시된 코드의 혼합 들여쓰기만 문서 지침의 공백으로 통일했다. 제품 코드는 변경하지 않았고 Consumer 등 제외 범위도 유지했다.
- 시간 계산 시작점·등록 및 취소의 스레드 허용 범위·핸들 정리 등 나머지 확인 사항은 확정하지 않았다. 제품 테스트는 실행하지 않았다.

## 검증

- PowerShell 검사로 이슈 문서 6개의 최상위 제목·코드 펜스·상대 링크 대상 파일·로컬 절대 경로 미포함을 확인했다.
- 요구사항의 등록 시그니처가 제시된 계약과 같고 이전의 등록 계약 미확정 문구가 제거됐음을 확인했다.
- 저장소 루트에서 `git diff --check`가 통과했으며 `feature/62`에서 변경이 이슈 문서에만 있음을 확인했다.
