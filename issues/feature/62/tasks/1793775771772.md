# 기반 타이머 위임과 부가 요구 제거

- 사용자 확인에 따라 지연 시간을 등록 시점부터 계산하도록 [요구사항](../REQUIREMENTS.md)에 반영했다.
- 앞선 기록에서 미확정으로 남긴 수명주기·스레드·상태·입력 처리를 별도 설계 과제로 확대하지 않고 기반 API의 계약에 맡겼다.
- 별도 타이머 목록 추적, 연결 종료 시 자동 정리, 추가 동기화·스레드 전달, 중복 취소·음수·0초의 자체 검증 요구를 제거했다. 타이머 사용·취소 시점은 호출자가 관리하며 기반 오류는 숨기지 않는다.
- 이번 RabbitMQ 구현은 Pika 타이머를 이용한다. 다른 연결 구현체의 타이머 구현 방식은 제한하지 않지만, 다른 브로커 지원이나 외부 스레드 타이머를 이번에 추가하지는 않는다.
- 이전 기록은 당시 분석으로 보존했다. 현재 범위는 정정한 요구사항과 작업 종합을 따른다.
- 제품 코드는 변경하지 않았으며 제품 테스트도 실행하지 않았다. 다음 단계는 확정된 계약에 대한 구현 계획 작성이다.

## 검증

- PowerShell 검사로 이슈 문서 7개의 제목·코드 펜스·상대 링크 대상 파일·로컬 절대 경로 미포함을 확인했다. 등록 시그니처 유지와 과도한 미확정·자동 정리 요구 문구 제거도 확인했다.
- 저장소 루트의 `git diff --check`가 통과했으며 `feature/62`의 변경은 이슈 문서에만 한정된다.
