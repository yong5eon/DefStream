# 타이머·Stream 샘플 검증

- 사용자 요청으로 실행 가능한 타이머 샘플과 기존 Stream 샘플의 연결 타이머 전환을 추가했다. 제품 Consumer·Worker·Executor는 변경하지 않았다.
- Mock 기반 샘플 실행에서 최초 예약 취소, 3회 콜백 실행과 재등록, 최신 핸들 취소, 소비 중단·채널·큐·연결 정리를 검증했다.
- 계획의 관련 5개 모듈은 `python -m unittest tests.test_protocol_contracts tests.rabbitmq.test_rabbitmq_timers tests.rabbitmq.test_rabbitmq_broker_methods tests.rabbitmq.test_rabbitmq_logging tests.rabbitmq.test_rabbitmq_timeouts -q`로 실행해 49개 중 45개 통과, 실제 브로커용 4개 skip이었다.
- 샘플 핸들러의 이벤트 타입을 기반 EventHandler 계약과 맞지 않는 구체 RabbitMQ Event에서 공통 Event로 수정했다. 두 샘플의 최종 Pylance 진단은 없고, 신규 샘플 구문 검사와 두 샘플·변경 테스트의 Python 3.9 문법 파싱도 통과했다.
- 타입 수정 후 샘플 동작 테스트와 기존 샘플 import·로깅 경계 테스트 2개를 묶어 다시 실행하여 통과했다. 실제 실행 환경은 앞선 기록과 같은 Python 3.12.10이며 출력만 UTF-8로 지정했다.
- 한국어·영어 매뉴얼에 샘플 링크·실행 명령·로컬 서버 전제 조건과 자원 정리 범위를 반영했다. 실제 RabbitMQ 서버 연결 제한은 해소되지 않았으므로 실제 샘플 실행까지 통과했다고 판단하지 않는다.
- 최종 문서 20개의 구조·샘플을 포함한 상대 링크·로컬 절대 경로 미포함을 확인했다. `git diff --check`가 통과했으며 제외한 제품 코드에 변경이 없고 실제 브랜치는 `feature/62`임을 확인했다.
