# 연결 타이머 계약과 RabbitMQ 등록·취소 구현

- 공통 연결 계약에 확정한 `Timer`, `TimerCallback`, `SetTimer`와 공개 import를 추가했다. `Timer`, `SetTimer`는 런타임 검사와 명시적 상속을 지원한다.
- RabbitMQ 연결은 `SetTimer`를 명시적으로 구현한다. `set_timer`는 기존 `connected()` 확인 후 `call_later(seconds, cb)`에 그대로 위임한다.
- 구체 `Timer`는 등록 당시 Pika 연결과 불투명 핸들만 보관하며, `remove`는 그 연결의 `remove_timeout`에 직접 위임한다. 취소 시 상위 연결을 다시 조회하지 않는다.
- Pika의 공개 메서드 선언은 반환·취소 핸들을 `int`로 표기하므로 해당 선언을 타입 힌트에 반영했다. 실제 핸들은 해석하거나 변환하지 않는다.
- Consumer·Worker·Executor와 종료 처리에는 손대지 않았다. 추가 스레드·콜백 래퍼·상태 관리·자동 정리 계층도 없다.
- 계약·위임 단위 테스트와 기존 opt-in 방식의 실제 RabbitMQ 테스트를 추가했다. 검증 결과는 후속 작업 기록에 남긴다.
