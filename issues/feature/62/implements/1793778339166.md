# 실행 가능한 연결 타이머 샘플 추가

- 사용자 요청에 따라 `samples/Broker/RabbitMQ/Sample.Timer.py`를 추가했다. 로컬 RabbitMQ에서 고유한 빈 큐를 구독하고 예약 취소, 1초 간격 세 번의 콜백 재등록과 소비 중단을 보여준다.
- 샘플은 기반 연결 타이머만 사용하며 현재 예약 핸들을 보관한다. 정상·오류 종료 시 타이머·소비 채널·샘플 큐·연결을 정리한다.
- 기존 Stream 샘플의 `threading.Timer`와 중계 함수를 제거하고 `con.set_timer(consumer.stop, 1)`로 교체했다. Consumer 구현은 변경하지 않았다.
- 기존 샘플의 실행 진입점 로깅 패턴을 유지하고 import 시 연결이나 루트 로깅 설정이 실행되지 않게 했다.
- 한국어·영어 매뉴얼에 샘플 링크·실행 방법·자원 정리 범위를 추가했다. 실제 브로커 실행 검증은 서버 연결 제한과 구분하여 후속 작업 기록에 남긴다.
