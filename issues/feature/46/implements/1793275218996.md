# 훅 오류 전파 보완 및 사용자 매뉴얼 반영

새 프로세스 실행 경로에서 setup·cleanup 예외가 기존처럼 작업 Future와 Pool 종료에 전달되도록 `src/Worker/Executor.py`를 보완했습니다. 프로세스의 예상치 못한 종료도 pending 작업의 실패로 드러내며, 정상 종료와 장애 폐기를 구분합니다.

`src/Broker/Consumer.py`의 기본값과 RabbitMQ Consumer의 명시적 활성화로 복구 적용 범위를 구분했습니다. Redis 및 복구를 지원하지 않는 기존 Consumer의 실패 시 Pool 정리 계약은 변경하지 않습니다.

한국어·영어 RabbitMQ, 생명주기 훅, 운영 매뉴얼에 공개 설정·복구 순서·훅 실행·Inspector 준비 상태와 ThreadPool 잔존 제한을 반영했습니다. 루트 README의 기존 Worker 소개·사용 경로는 유지하고 상세 설정은 매뉴얼에서 안내합니다. 실제 검증 경과는 [검증 기록](../tasks/1793275218995.md)에 연결합니다.
