# 폐기된 ThreadPool의 중복 오류 로그 방지

[남은 리뷰](https://github.com/yong5eon/DefStream/pull/49#discussion_r4412634785)에 따라 `src/Worker/Executor.py`의 collect_results에서 처리한 worker Future를 추적하도록 변경했습니다. 완료된 실행 단위의 실패는 한 번만 처리하며 다른 실행 단위에서 나중에 발생하는 오류도 각각 처리합니다. 예외 객체가 같아도 서로 다른 worker의 실패를 누락하지 않습니다.

기존 fail의 오류 전파·로깅 정책과 이전 스레드의 작업 완료 후 정리는 유지합니다. 동일 실패를 다시 관찰하는 생산 경계를 수정한 것이므로 로그를 숨기는 전역 최초 오류 조건은 추가하지 않았습니다.

복구·생명주기 대상 검증 결과는 [작업 기록](../tasks/1793279849391.md)에 정리했습니다. 공개 API·설정·사용법의 변경은 없어 상세 매뉴얼은 갱신하지 않았습니다.
