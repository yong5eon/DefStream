# 실행기 세대 교체와 Worker 복구 경로 구현

`src/Worker/Pool.py`에 Pool 객체를 유지하는 내부 실행기 교체 경로를 추가하고, 이전 Future·슬롯을 별도 세대로 분리했습니다. `src/Worker/Executor.py`의 프로세스 실행 단위는 공개 multiprocessing Process API로 소유·추적하여 이전 작업 프로세스를 강제 종료할 수 있도록 변경했습니다. 확인한 Python 3.12에는 표준 ProcessPoolExecutor의 공개 강제 종료 API가 없으며, 지원 Python 3.9 이상을 유지하기 위해 사설 executor 속성 조작을 피했습니다.

`src/Worker/Worker.py`에서 소비 장애 후 이전 delivery를 무효화하고 실행기·연결·Consumer를 교체하도록 구현했습니다. 사용자 확인대로 첫 시도는 즉시 수행하고 실패한 시도 사이에만 고정 간격을 적용하며, 연결·전체 구독 복구 성공 시 다음 장애의 시도 횟수는 다시 시작합니다. 이전 완료·실패 및 예약 콜백의 정산·새 상태 변경은 세대 검사로 차단합니다.

RabbitMQ Consumer에 소비 루프의 예상치 못한 종료 감지·주기적 이벤트 깨우기·ACK timeout 구분 및 복구 오류 분류를 추가했습니다. 명시적 stop의 종료는 별도로 유지합니다.

현재는 구현과 대상 테스트 보완 중입니다. 최종 검증·매뉴얼·종합 결과는 아직 완료되지 않았습니다.
