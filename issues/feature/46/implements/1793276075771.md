# 복구 가능 판별 메서드 이름 변경

사용자 요청에 따라 `Recoverable` Protocol과 RabbitMQ Consumer의 판별 메서드를 `recoverable`에서 `is_recoverable`로 변경했습니다. Worker의 소비 장애·재연결 실패 판별 호출과 Protocol·오류 분류 테스트도 같은 이름으로 맞췄습니다.

복구 정책과 런타임 Protocol 판별 방식은 유지하며 이전 이름의 별칭은 추가하지 않았습니다. [이전 구현 기록](./1793275899489.md)의 이름 유지 결정은 이번 변경으로 대체합니다.
