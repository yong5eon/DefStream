# Python 3.9·3.10 테스트 패치 대상 수정

`tests/test_worker_recovery.py`의 `run_worker()`에서 문자열 경로 대신 `import_module('DefStream.Worker.Worker')`와 `patch.object(..., 'startup')`를 사용했습니다. 이전 Python의 mock 경로 탐색이 모듈과 같은 이름으로 공개된 Worker 클래스를 선택하는 문제를 피하고 실제 실행 모듈의 startup을 패치합니다. 다른 테스트에서도 사용하는 모듈 명시 방식을 따랐습니다.

치명적 실패 테스트의 정리 코드는 monitor가 생성된 경우에만 join하도록 변경했습니다. Worker 시작 전 오류가 발생해도 미생성 monitor에 대한 정리 오류가 원래 예외를 가리지 않게 했습니다. 정상 검증의 작업 실행·실패 전파·대기 상한 단언은 유지했습니다.

제품 복구 로직과 공개 API는 변경하지 않았습니다. 재현 및 회귀 결과는 [호환성 검증 기록](../tasks/1793276518341.md)에 정리했습니다.
