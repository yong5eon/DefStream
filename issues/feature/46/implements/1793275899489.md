# 복구 지원 판별을 Protocol로 전환

사용자 요청에 따라 `src/Broker/Protocol.py`에 런타임 검사 가능한 `Recoverable`을 정의하고 `DefStream.Broker`에서 공개했습니다. 기존 메서드명 `recoverable`은 유지했습니다.

Worker는 `isinstance(consumer, Recoverable)`로 지원 여부를 판별하고, 복구 재시도에서도 같은 계약을 사용합니다. 기본 Consumer와 RabbitMQ Consumer의 지원 플래그를 제거하고 기본 Consumer의 `recoverable()`도 제거하여 Redis가 의도치 않게 계약을 충족하지 않도록 했습니다.

복구 횟수·간격·오류 분류·실행기 격리 정책은 변경하지 않았습니다. 구조적 지원과 비지원 판별 테스트를 추가했으며 80개 대상 테스트가 통과했습니다. 정적 분석 제한을 포함한 결과는 [Protocol 전환 검증](../tasks/1793275955973.md)에 기록했습니다.
