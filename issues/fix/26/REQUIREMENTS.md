# 요구사항 명세서: PyPI용 독립 설명 문서 작성

## 출처

- 이슈: [ISSUE.md](./ISSUE.md)
- 변경 유형: 일반 변경

## 목적

PyPI 프로젝트 페이지에서 외부 링크가 포함된 설명을 사용할 때 발생하는 링크 문제를 피하고,
DefStream의 주요 정보를 외부 문서에 의존하지 않고 확인할 수 있도록 PyPI 전용 영문 설명 문서를 제공한다.

## 범위

### 포함

- PyPI에 표시할 내용을 별도의 `SETUP.md`로 작성한다.
- `SETUP.md`는 외부 링크 없이 자체적으로 이해할 수 있는 영어 문서여야 한다.
- `setup.py`에서 `SETUP.md`를 읽어 배포 메타데이터의 장문 설명으로 사용한다.

### 제외

- 기존 프로젝트용 `README.md` 및 `README.en.md`의 구조나 내용을 변경하는 작업.
- PyPI 장문 설명 외의 패키지 메타데이터 URL 변경.
- DefStream의 기능, 공개 API, 설치 의존성 또는 런타임 동작 변경.

## 확정 요구사항

| ID | 요구사항 |
| --- | --- |
| PYPI-01 | PyPI 장문 설명은 프로젝트 README가 아니라 저장소 루트의 `SETUP.md` 내용을 사용해야 한다. |
| PYPI-02 | `SETUP.md`의 본문은 영어로 작성하고, 외부 웹사이트로 연결되는 링크를 포함하지 않아야 한다. |
| PYPI-03 | `SETUP.md`만 읽어도 패키지의 용도와 기본 설치 방법을 파악할 수 있어야 한다. |
| PYPI-04 | `SETUP.md`는 PyPI에서 렌더링할 수 있는 Markdown 형식으로 작성되어야 한다. |
| PYPI-05 | `SETUP.md`를 읽을 때는 UTF-8 인코딩을 사용해야 한다. |
| PYPI-06 | 현재 `README.md`를 장문 설명으로 사용하는 구성을 `SETUP.md` 사용으로 변경하되, 그 외 패키지 메타데이터와 런타임 동작은 변경하지 않아야 한다. |

## 제약사항

- PyPI 설명은 외부 문서나 링크를 열지 않아도 핵심 정보를 제공해야 한다.
- 문서에 포함하는 설치 명령과 패키지 정보는 현재 DefStream의 배포 설정과 일치해야 한다.
- 이번 변경은 PyPI 표시용 문서와 해당 문서를 지정하는 메타데이터에 한정한다.
- 이슈에는 `SETUP.md`의 구체적인 목차나 필수 사용 예제 범위가 지정되어 있지 않으므로, 기존 README의 모든 내용을 복제하는 것은 요구하지 않는다.

| --- | --- |

| PYPI-AC-02 | `SETUP.md`에는 외부 URL로 이동하는 Markdown 링크나 HTML 링크가 없다. |

| PYPI-AC-05 | 패키지 메타데이터를 생성하거나 확인했을 때 장문 설명의 내용이 `SETUP.md`와 일치한다. |
