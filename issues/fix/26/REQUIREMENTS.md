# 요구사항 명세서: PyPI용 독립 설명 문서 작성

## 출처

- 이슈: [ISSUE.md](./ISSUE.md)
- 변경 유형: 일반 변경

## 목적

PyPI 프로젝트 페이지에서 외부 링크가 포함된 설명을 사용할 때 발생하는 링크 문제를 피하고,
DefStream의 주요 정보를 외부 문서에 의존하지 않고 확인할 수 있도록 PyPI 전용 영문 설명 문서를 제공한다.

## 범위

### 포함

- PyPI에 표시할 내용을 별도의 `README.setup.md`로 작성한다.
- `README.setup.md`는 외부 문서 링크 없이 자체적으로 이해할 수 있는 영어 문서여야 한다.
- 기존 영문 사용 설명서의 자체 포함된 내용을 전체적으로 반영한다. 외부 링크는 링크 대상을 제거하고 표시 문구를 일반 텍스트로 남긴다.
- 영문 사용 설명서의 유효한 목차, 설명, 표, 예제 및 운영 안내를 보존한다. 저장소 내부 자료를 가리키는 경로만 남기지 말고 필요한 내용을 인라인으로 설명하거나, 이미 본문 예제로 대체된 항목은 제외한다.
- `setup.py`에서 `README.setup.md`를 읽어 배포 메타데이터의 장문 설명으로 사용한다.

### 제외

- 기존 프로젝트용 `README.md` 및 `README.en.md`의 구조나 내용을 변경하는 작업.
- PyPI 장문 설명 외의 패키지 메타데이터 URL 변경.
- DefStream의 기능, 공개 API, 설치 의존성 또는 런타임 동작 변경.

## 확정 요구사항

| ID | 요구사항 |
| --- | --- |
| PYPI-01 | PyPI 장문 설명은 프로젝트 README가 아니라 저장소 루트의 `README.setup.md` 내용을 사용해야 한다. |
| PYPI-02 | `README.setup.md`의 본문은 영어로 작성하고, PyPI 페이지에서 깨질 수 있는 외부 링크를 포함하지 않아야 한다. |
| PYPI-03 | `README.setup.md`만 읽어도 패키지의 용도, 주요 기능, 설치 방법 및 일반적인 사용 방법을 파악할 수 있어야 한다. |
| PYPI-04 | `README.setup.md`에는 기존 영문 사용 설명서 중 외부 문서에 의존하지 않는 주요 설명, 예제 및 운영 안내를 반영해야 한다. |
| PYPI-05 | `README.setup.md`는 PyPI에서 렌더링할 수 있는 Markdown 형식으로 작성되어야 한다. |
| PYPI-06 | `README.setup.md`를 읽을 때는 UTF-8 인코딩을 사용해야 한다. |
| PYPI-07 | 현재 README를 장문 설명으로 사용하는 구성을 `README.setup.md` 사용으로 변경하되, 그 외 패키지 메타데이터와 런타임 동작은 변경하지 않아야 한다. |

## 제약사항

- PyPI 설명은 외부 문서나 링크를 열지 않아도 핵심 정보를 제공해야 한다.
- 영문 사용 설명서의 자체 포함된 사용 안내는 문서 분량을 줄이기 위해 임의로 생략하지 않는다.
- PyPI에서 열 수 없는 저장소 내부 파일·폴더 경로를 설명이나 예제 대신 남기지 않는다. 필요한 내용은 문서 안에 설명하고, 이미 설명된 항목의 별도 파일 참조는 제거한다.
- 문서에 포함하는 설치 명령과 패키지 정보는 현재 DefStream의 배포 설정과 일치해야 한다.
- 이번 변경은 PyPI 표시용 문서와 해당 문서를 지정하는 메타데이터에 한정한다.
- 원본 `README.md`와 `README.en.md`는 변경하지 않고, PyPI 전용 문서만 별도 관리한다.
