# 로그 레벨 조정 검증

[구현 기록](../implements/1793257519898.md)의 변경을 검증했습니다. 명령은 저장소 루트에서 실행했으며 `DefStream`이 현재 저장소의 `src/`를 가리키는 환경입니다.

## RabbitMQ 테스트

```shell
python -m unittest discover -s tests -p "test_rabbitmq*.py"
```

- 결과: 52개 실행, 통과, 3개 건너뜀(외부 RabbitMQ 서버가 필요한 opt-in 통합 테스트)

## 출력량 재현

모의 `BlockingConnection`으로 `Connection.connect()`·`close()`를 3회 반복하고 루트 핸들러 레벨별 출력 건수를 셌습니다.

| 핸들러 레벨 | 출력 건수 |
| --- | ---: |
| INFO | 0 |
| DEBUG | 9 (시도·성공·종료 × 3) |

제공 로그의 216건과 같은 종류의 정상 연결 로그는 INFO에서 더 이상 출력되지 않습니다. 실제 애플리케이션과 RabbitMQ 서버에서는 실행하지 않았습니다.

## 전체 테스트 변경 전후 비교

```shell
python -m unittest discover -s tests
```

- 기본 콘솔 인코딩 `cp949`에서는 Worker 시작 배너 출력의 `UnicodeEncodeError` 등으로 다수 실패했습니다. 환경 문제로 판단해 `PYTHONIOENCODING=utf-8`로 다시 실행했습니다.
- UTF-8 환경의 변경 후 결과: 267개 실행, 실패 3, 건너뜀 15
- 같은 환경에서 `Connection.py`·`test_rabbitmq_logging.py`만 `HEAD`로 임시 복원한 변경 전 결과: 267개 실행, 실패 3, 건너뜀 15. 비교 후 변경을 다시 적용했습니다.
- 남은 실패 3건은 모두 `test_broker_packaging`입니다. 설치된 editable 배포에 `DefStream/Broker/Implements/*/__init__.py`가 없다는 검사로, 이번 변경과 무관한 기존 환경 문제입니다. 수정하지 않았습니다.
