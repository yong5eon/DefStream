# 변경된 로거 이름에 맞춘 테스트·샘플·문서 정합성 확인

소스의 현재 이름에 맞춰 테스트 기대값을 `Worker`, `Task`, `Worker.Inspector.<클래스명>`으로 갱신했습니다. Worker 샘플과 Operations 로깅 예제에 독립된 `Task` 필터를 추가하고, RabbitMQ 안내 및 이슈 요구사항·계획·종합 문서도 현재 이름을 반영하도록 정리했습니다. 제품 소스와 import 경로는 변경하지 않았습니다.

저장소 `src`를 직접 로드하는 임시 실행기에서 `test_logging`, `test_inspector_logging`, `test_inspector`, `test_rabbitmq_logging`, `test_redis_logging`, `test_runner_hooks`, `test_specifications`, `test_task_messages`, `test_worker`를 실행했습니다. 총 126개 테스트가 통과하고 6개는 건너뛰었습니다. 실행에 사용한 임시 실행 파일은 검증 후 삭제했습니다.

변경한 Python 파일 15개에 대한 Pylance 구문 검사는 모두 오류가 없었습니다. `git diff --check`가 통과했고, 문서와 이슈 기록의 로컬 링크 113개를 확인해 깨진 링크가 없었습니다. 전체 브로커 통합 테스트는 외부 서비스 의존성으로 이 검증 범위에 포함하지 않았습니다.
