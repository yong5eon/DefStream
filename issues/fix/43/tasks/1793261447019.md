# 확장된 로거 변경 검증

저장소 `src`를 직접 로드해 브로커 로깅, Redis 로깅, RabbitMQ RPC, 프로토콜 공개 계약, Inspector 로깅 테스트와 Worker 로거 관련 선택 테스트를 실행했습니다. 총 65개 테스트가 통과했습니다.

검증은 Worker 클래스 이름(`Worker.Worker`, `Worker.Run`, `Worker.Executor`, `Worker.Pool`, `Worker.ThreadPool`, `Worker.ProcessPool`), Inspector 공용·확장 이름, Worker·Broker·Inspector의 상위 계층 및 루트 전파, 샘플 필터와 기존 Worker·Inspector import 경로를 확인했습니다. Descriptor·Validator 소스에서는 `getLogger` 또는 `logging` 사용이 발견되지 않았고, `git diff --check`도 통과했습니다.

더 넓은 테스트 모음에는 ProcessPool 기반 테스트가 포함되어 표준 입력 임시 실행기에서 종료되지 않아 중단했습니다. 해당 시도는 통과로 계산하지 않았습니다. 이전 기록의 editable 설치 환경 패키징 제한과 외부 브로커 통합 테스트 미실행 상태도 그대로입니다.
