# 브로커 로거 이름 변경

RabbitMQ 클래스의 로거 이름을 `DefStream.Broker.RabbitMQ.<클래스명>`에서 `Broker.RabbitMQ.<클래스명>`으로, Redis 클래스의 로거 이름을 `DefStream.Broker.Implements.Redis.<클래스명>`에서 `Broker.Redis.<클래스명>`으로 변경했습니다. 브로커 로거 이름만 바꾸고 구현 모듈·import 경로와 Worker·Inspector 로거는 유지했습니다.

새 이름이 `DefStream` 로거 계층 밖에 있으므로 샘플의 RabbitMQ·Redis 로그 필터를 함께 바꿨습니다. 운영·RabbitMQ·Redis 한국어·영어 매뉴얼에는 새 계층, 전파 위치와 기존 로거 이름을 사용한 애플리케이션 필터·핸들러의 갱신 필요성을 반영했습니다.

로거 이름과 계층 전파를 검증하도록 RabbitMQ 로깅 테스트의 기준 이름과 상위 계층을 갱신하고, Redis 로깅 테스트에 새 어댑터 상위 이름 및 루트 전파 검증을 추가했습니다. RPC 경고 캡처 테스트도 새 로거 이름을 사용합니다. 로그 내용·수준·핸들러 설정, 민감정보 보호와 예외 전파 동작은 변경하지 않았습니다.
