# Worker·Inspector 로거 계층 변경

사용자가 의도한 범위를 확인해 브로커뿐 아니라 Worker·Inspector 로거도 변경했습니다. Worker 관련 클래스는 `DefStream.<클래스명>`에서 `Worker.<클래스명>`으로 옮겼고, Inspector·Server·RequestHandler 및 Inspector 확장 로그는 `Worker.Inspector` 계층을 사용합니다. Broker 로거는 앞 단계에서 `Broker.RabbitMQ`와 `Broker.Redis` 계층으로 변경했습니다.

새 이름이 `DefStream` 계층에 포함되지 않으므로 Worker 샘플 필터를 `Worker`로 바꾸고 RabbitMQ·Redis 샘플에는 Broker 필터를 추가했습니다. Operations의 한국어·영어 설명 및 RabbitMQ 한국어·영어 매뉴얼에서 로거 계층과 기존 이름에 의존한 설정의 갱신 필요성을 반영했습니다. Descriptor와 Validator에는 로거 선언이 없어 변경하지 않았습니다.

테스트의 클래스별 이름 기대값, 계층별 로그 캡처와 기존 필터 검증을 새 이름으로 갱신했습니다. import 경로(`DefStream.Worker`, `DefStream.Inspector`)는 제품·샘플·문서 전반에서 유지했습니다.
