# 변경 사항

- Inspector의 대시보드 확장 이름을 `Dashboard`에서 `Status`로, URL을 `/dashboard`에서 `/status`로 변경합니다.
- 상태 확인 확장 이름을 `HealthCheck`에서 `Ping`으로, URL을 기존 `/status`에서 `/ping`으로 변경합니다.
- 기존 클래스 이름과 모듈 경로는 호환 별칭으로 제공하지 않습니다. Inspector 설정에서 새 이름과 경로를 사용하도록 수정하세요.

상세 요구사항은 [REQUIREMENTS.md](./REQUIREMENTS.md)를 참고하세요.
