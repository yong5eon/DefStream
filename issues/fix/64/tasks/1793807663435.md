# 변경 전 직접 상속 회귀 테스트 실패 확인

제품 코드를 변경하기 전에 저장소 루트에서 기존 프로젝트 가상환경의 `python`으로 다음 명령을 실행했다.

```shell
python -X utf8 -m unittest tests.test_protocol_contracts.ProtocolContractTests.test_recovery_capability_is_structural_and_opt_in
```

테스트 1개가 실패했다. 실패 지점은 `Recoverable in RabbitConsumer.__bases__` 검증이며, 실제 직접 부모는 공통 Consumer 하나뿐이었다. 이는 [요구사항 R1·R5](../REQUIREMENTS.md)의 미충족을 정확히 검출한 결과다.

변경 전 Pylance 진단에서 제품 파일에는 진단이 없었다. 계약 테스트에는 기존 지역 매개변수 `cb`, `seconds` 미사용 힌트 2개만 있었으며 오류는 없었다.

다음 단계는 import와 상속 선언 변경 및 변경 후 검증이다.
