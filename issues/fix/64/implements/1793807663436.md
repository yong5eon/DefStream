# RabbitMQ Consumer의 Recoverable 명시적 상속 적용

[RabbitMQ Consumer](../../../../src/Broker/Implements/RabbitMQ/Consumer.py)의 기존 `DefStream.Broker` import에 `Recoverable`을 추가하고 직접 부모를 `BaseConsumer`, `Recoverable` 순서로 선언했다.

Python 지침의 복수 상속 선언 형식에 따라 여러 줄로 표기했으며, 명세의 `Consumer(BaseConsumer, Recoverable)`와 동일한 상속 관계다.

생성자와 `is_recoverable` 구현은 변경하지 않았다. Worker가 구조적 런타임 판별과 기존 오류 분류 결과를 사용하는 흐름도 유지했다. 공통 Consumer, Redis Consumer, Protocol 정의와 Worker·Executor는 수정하지 않았다.

회귀 테스트 보강은 [이전 구현 기록](./1793807653096.md), 변경 전 실패 확인은 [작업 기록](../tasks/1793807663435.md)에 기록했다. 변경 후 검증은 다음 단계에서 수행한다.
