# 명시적 상속과 Consumer 생성의 회귀 테스트 보강

[Protocol 계약 테스트](../../../../tests/test_protocol_contracts.py)의 `test_recovery_capability_is_structural_and_opt_in`에 다음 검증을 추가했다.

- `Recoverable`이 RabbitMQ Consumer의 직접 부모에 포함되는지 확인한다.
- RabbitMQ Consumer가 추상 클래스가 아닌지 확인한다.
- Mock 연결과 디코더로 실제 인스턴스를 생성하고 `isinstance(consumer, Recoverable)`를 확인한다.
- 생성한 Consumer의 `close`를 테스트 정리 작업으로 등록한다.

기존 구조적 구현체와 공통 Consumer·Redis Consumer의 판별 검증은 유지했다. 제품 코드는 아직 변경하지 않았으며, 다음 단계에서 직접 상속 검증이 실패하는지 확인한다.
