# 이슈와 패키징 계약 확인

원본 #53의 `fix` 레이블과 댓글 부재를 확인하고 본문을 README에 보존했다. 사용자 확인에 따라 `master`에서 `fix/53`을 생성했다. 시작 시 작업 트리는 깨끗했다.

두 구현체가 코어에 포함된다는 기존 `tests/test_broker_packaging.py`와 매뉴얼 계약을 확인했다. CI에도 단일 배포물 및 이전 `packages/DefStream` 경로를 가정하는 부분이 있어 이번 다중 배포 빌드·검사와 함께 연결해야 한다.

빌드 도구가 없는 환경을 확인한 뒤 저장소 밖 Python 3.13 가상환경에 검증 도구를 준비했다. 요구사항과 계획을 작성했으며 다음 단계는 대상별 배포 구현이다.
