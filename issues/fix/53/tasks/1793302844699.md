# 소스 포함 목록 통합 회귀 검증

Python 3.9에서 `MANIFEST.in`을 제거한 상태로 검증했다. 명령은 저장소 루트 기준이다.

```shell
python scripts/build_distributions.py --outdir dist/inline-manifest --no-isolation
python scripts/check_distributions.py --dist-dir dist/inline-manifest --editable
python -m unittest discover -s scripts/tests -t scripts -p 'test_*.py'
```

세 wheel·세 sdist 빌드, 독립 sdist 재빌드, 네 설치 조합, 파일 소유권, 일반 구현체 추가·제거와 EXTRAS editable 교체·해제·버전 갱신·새 파일·두 환경 격리가 통과했다. 단위 테스트는 19개 통과했다.

추가로 아카이브를 직접 검사해 세 sdist 모두 필요한 보조 파일을 각각 한 번 포함하고 `MANIFEST.in`은 포함하지 않음을 확인했다. 일반 wheel의 제품 파일 내용은 직전 산출물과 동일하며 보조 스크립트가 설치 파일에 섞이지 않았다. `setup.py`와 패키징 검사 코드의 Pyright 오류는 0개다.

공용 가상환경을 재설치하거나 제품 전체 테스트를 반복하지 않았다. 설치 계약은 유지되며 고객 영향은 없다. 커밋·푸시는 하지 않았다.
