# 고객용 문서의 반복 수식어와 임시 빌드 설정 설명 제거

후속 요청에 따라 한영 Packaging·시작 안내·목차·README에서 소스 수정 안내 앞에 반복한 프로젝트명과 “자체의” 수식어를 제거했다. 현재 변경 로그도 같은 표현으로 정리했다.

`DEF_BUILD_TARGET`의 허용 값·기본값·editable 무시 설명을 고객용 매뉴얼에서 제거했다. 빌드 스크립트로 실행하는 명령은 유지했다. 실제 코드·설정·설치 동작과 과거 기록은 변경하지 않았다.

문서 변경에 한정하므로 제품 테스트는 반복하지 않았다. 한영 명령·제목 구조 일치, 상대 링크와 코드 펜스, 제거 대상의 잔존 여부 및 `git diff --check` 검사를 모두 통과했다.
