# 선택 editable 링크 트리 검증

Python 3.9에서 `python scripts/build_distributions.py --outdir dist/editable-final --no-isolation`와 `python scripts/check_distributions.py --dist-dir dist/editable-final --editable`를 실행해 통과했다. 검증 버전은 환경변수로만 지정했다.

- 코어·두 구현체의 wheel/sdist, 독립 sdist 재빌드, 네 설치 조합과 파일 소유권 검사
- 실제 import와 import hook을 우회하는 표준 `PathFinder`의 선택 유무 일치
- 기존 소스 변경·새 파일 재설치·editable 구현체 제거 후 파일과 빈 namespace 디렉터리 부재
- 같은 소스를 사용하는 두 가상환경에서 서로 다른 구현체 선택 유지
- `python -m unittest discover -s scripts/tests -t scripts -p 'test_*.py'`: 릴리즈 준비 6개와 링크 관리 6개, 총 12개 통과

일반 wheel에 editable 보조 모듈이 없고 각 sdist에는 보조 소스가 포함됨을 검사했다. 새 코드의 Windows 타입 검사와 공통 관리 코드의 Linux 대상 타입 검사도 통과했다. Linux 실제 실행을 검증한 것은 아니다.

작업공간 환경의 기존 코어 연결이 다른 작업 트리를 가리켜 사용자에게 확인했고, 승인을 받아 현재 작업공간 소스로 재설치했다. 버전과 코어만 선택한 상태를 유지했다. 작업공간의 5개 동시 Python 시작에서 선택 격리·실제 import·파일 잠금을 검사했고 `pip check`도 통과했다.

DefPixel에서는 같은 구조로 정적 분석 import 오류 해소와 사용자의 Pylance 밑줄 해소 확인까지 받았다. 실제 브로커·원격 CI·게시 권한 미검증 상태는 유지한다.
