# 리뷰 지적의 재현과 수정 검증

기존 helper에 신규 테스트를 먼저 추가하여 hardlink 원본 교체 중 코어 파일 소실, 미관리 파일이 있는 선택 해제 실패, 링크 생성 실패 시 기존 파일 소실의 3건을 모두 재현했다. 수정 후 최소 Python 3.9 패키징 단위 테스트 22개, Linux Python 3.9 링크 테스트 10개와 helper·테스트의 Pyright 검사를 통과했다.

저장소 루트에서 실행한 주요 검증:

```shell
python -m unittest discover -s scripts/tests -t scripts -p "test_*.py"
python -m pyright scripts/editable_view.py scripts/tests/test_editable_view.py
```

Python 3.9에서 `python scripts/check_distributions.py --dist-dir dist/inline-manifest --editable`을 통과했다. 기존 일반 배포 산출물의 소유권·sdist 재빌드·네 설치 조합·설치 수명주기를 확인하고, 현재 수정된 helper를 복사한 로컬 소스로 editable 선택 교체·해제·로컬 버전 갱신·새 파일 반영·두 환경 격리를 검증했다. 이번 검증을 새 일반 배포 산출물의 재빌드로 보고하지 않는다.

세 프로젝트 helper와 링크 테스트의 SHA256이 각각 동일하다. Pylance의 helper·테스트 구문 검사에서 오류가 없었다. 한영 매뉴얼·변경 로그의 계약을 대조했다. 이전 PR의 원격 CI 통과는 확인했으나 이번 미커밋 수정의 원격 CI는 실행하지 않았다. 브로커 실서버 테스트는 이번 범위에서 반복하지 않았고 공유 개발 환경은 변경하지 않았다. 커밋·푸시·리뷰 해결 처리·병합·배포는 수행하지 않았다.
