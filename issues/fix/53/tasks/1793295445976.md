# 배포 조합과 기존 동작 검증

Python 3.13에서 코어·RabbitMQ·Redis의 세 wheel/sdist를 같은 검증 버전으로 만들고 `python scripts/check_distributions.py --editable`를 실행했다. 파일 소유권 중복 부재, 세 sdist의 독립 재빌드, 기본·각 단일 extra·전체 extra의 네 설치 조합, 추가 설치·재설치·한 구현체 제거 및 editable 소스 연결을 확인했다.

설치된 패키지에 대한 첫 전체 unittest는 Windows cp949 출력에서 기존 시작 배너의 Unicode 문자를 출력하지 못해 실패했다. 제품 코드는 변경하지 않고 `PYTHONUTF8=1`로 실행 환경을 맞추어 재실행했다. 311개를 수행해 통과했다(실제 브로커가 필요한 항목 등 15개 건너뜀). 변경한 패키징 메타데이터 테스트도 이 실행에 포함됐다.

`scripts/`의 릴리즈 준비 단위 테스트 6개는 통과했다. PyPI 응답을 모킹하여 새 릴리즈, 기존 파일 재사용·불일치, 누락 배포물과 빌드 번호 오류를 검사했으며 실제 게시하지 않았다.

잘못된 빌드 대상 거부와 YAML·내장 Python·Markdown 검사도 통과했다. 최소 지원 Python 및 이전 통합 버전 전환 검증을 이어간다.
