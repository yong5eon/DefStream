# 환경 전환 안내 제거와 개발용 설치 설명 정리

초기 프로젝트에 불필요한 기존 환경 전환 안내를 모두 제거하고, 소스를 직접 수정하고 싶은 독자를 기준으로 설명해 달라는 후속 요청을 반영했다.

- 한영 Packaging에서 기존 배포물 제거·재설치·롤백 안내와 editable 전환 절차를 제거했다.
- 개발 설치의 목적, editable·`.`·`-e`의 의미, 실행 위치와 pip 조건을 먼저 설명했다. 구현체 선택 예시, 목록 교체·해제와 코드 수정 후 확인 절차를 구분했다.
- 루트 README, 매뉴얼 목차, GettingStarted와 현재 고객용 변경 로그의 전환 안내도 제거했다.
- 선택 격리·외부 라이브러리 처리·재실행 조건·Windows 링크 제약은 유지하되 쉬운 표현으로 정리했다.

과거 이슈 원문과 단계별 수행 기록은 사실 보존을 위해 변경하지 않았다. 코드와 설치 계약은 바꾸지 않은 문서 수정이므로 제품 테스트를 반복하지 않았다. 한영 Packaging의 명령·제목 구조 일치, 변경 문서의 상대 링크·코드 펜스·개인 경로 비노출과 `git diff --check`를 통과했다. 사용자 문서·README에서 기존 패키지 설치 환경의 전환 안내가 남아 있지 않음을 확인했다. 브로커 큐 변경에 관한 별개의 migration 설명은 유지했다.
