# 다중 배포 CI와 설치 문서 연결

CI와 게시 준비를 코어·RabbitMQ·Redis 배포물로 확장했다. 빌드 스크립트는 버전을 한 번 고정하며 게시 준비는 이름·버전·빌드 번호·기존 파일 해시를 검사한다. 실제 게시 순서는 구현체 후 코어이다.

CI의 이전 `packages/DefStream` checkout과 후속 경로를 저장소 루트 기준으로 함께 변경했다. 전체 wheel 설치, 네 extras 조합과 editable 검사, 릴리즈 준비 단위 테스트 및 기존 제품·UI 테스트를 연결했다. 기존 패키징 테스트는 코어 대신 각 구현체 배포물이 파일을 소유하고 코어 extras가 같은 버전 구현체를 선택하는 계약으로 수정했다.

README 세 문서와 한국어·영어 매뉴얼에서 기존 통합 배포 안내를 새 배포 경계로 갱신했다. 과거 별도 어댑터·통합 배포의 안전한 제거 후 전환과 editable 사용법을 안내한다.
