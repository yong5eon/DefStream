# Python 3.9 소켓 타임아웃 로그 검증 수정

`tests/test_inspector_logging.py`의 `test_response_write_timeout_through_run_is_logged_as_warning`에서 대문자 `Timeout` 부분 문자열 대신 `SocketTimeout.__name__`을 사용한 `error_type` 필드를 검사하도록 변경했다.

Python 3.9의 `socket.timeout`은 이름이 `timeout`인 별도 타입이고 이후 버전의 `TimeoutError` 별칭과 이름이 다르다. `InspectorServerHandler.log_exception`은 실제 타입 이름을 기록하고 두 타입 모두 WARNING으로 처리하므로 제품 로직과 로그 형식은 변경하지 않았다. 단일 로그·WARNING 수준 검증도 그대로 유지했다. [재현·검증 기록](../tasks/1793517548590.md).
