# 최소 런타임 검증 도구와 격리 범위 명확화

Python 3.9의 기본 가상환경에 포함된 오래된 pip가 검증용 의존성을 가져오지 못하는 문제를 확인했다. `scripts/check_distributions.py`의 `python_in()`에서 실행 주체의 `pip --python`으로 새 검증 환경에 `pip>=23`을 설치하도록 보완했다. 실패는 기존 `check()`를 통해 명시적으로 전파한다. CI와 개발용 빌드 안내에도 같은 도구 요구사항을 반영했다.

Python 3.9에 없는 `contextlib.chdir` 대신 릴리즈 준비 테스트에서 작업 디렉터리를 복구하는 context manager를 사용했다. 제품의 최소 Python 요구사항은 변경하지 않았다.

한국어·영어 Packaging 매뉴얼에 sdist는 공통 소스를 포함하며, 선택 구현체 파일 격리는 wheel과 최종 설치 파일에 적용됨을 명시했다. 최종 검증 결과는 [검증 기록](../tasks/1793295838893.md)에 정리했다.
