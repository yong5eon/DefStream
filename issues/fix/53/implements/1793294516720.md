# 코어와 구현체별 배포 구성

`setup.py`에 `DEF_BUILD_TARGET=core|RabbitMQ|Redis` 선택을 추가했다. 코어에서 선택 어댑터 하위 패키지를 제외하고, 각 구현체 배포물에는 자기 하위 패키지만 포함한다. 코어 extras는 동일 버전 구현체 배포물에, 구현체는 코어와 외부 드라이버에 의존한다.

대상별 `build`와 기본 egg-info 경로를 분리하고 sdist에 `.distribution-target`을 기록해 독립 재빌드가 같은 대상을 선택하게 했다. 잘못된 대상과 sdist 대상 변경은 명시적으로 실패한다. PEP 517 빌드 의존성은 `pyproject.toml`에 선언했다.

개발 설치는 코어에 strict 링크 트리, 구현체에 선택 하위 패키지 전용 editable finder를 사용한다. 공통 부모 파일을 구현체에 중복 포함하지 않는다. 다중 빌드·파일 소유권·조합별 설치 검사 스크립트를 추가했으며 검증을 이어간다.
