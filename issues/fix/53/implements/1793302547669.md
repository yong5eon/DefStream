# 소스 배포 포함 목록의 setup.py 통합

사용자 요청에 따라 `MANIFEST.in`을 제거하고 기존 `TargetEggInfo.find_sources()`를 확장했다. 부모 명령의 기본 파일 수집을 유지한 뒤 `scripts/editable_view.py`, `scripts/build_backend.py`, `scripts/build_distributions.py`를 추가하고 정렬·중복 제거한 목록을 `SOURCES.txt`에 기록한다. sdist와 메타데이터가 같은 목록을 사용하며 일반 wheel의 설치 파일은 변경하지 않는다.

`scripts/check_distributions.py`의 editable 검증 소스 복사에서 제거한 파일을 제외하고, 각 sdist에 필요한 세 보조 파일이 실제 포함되는지 검사하도록 했다. 한영 Packaging 매뉴얼에 목록 관리 위치를 반영했다.

타입 검사는 오류 없이 통과했다. 최소 Python 3.9의 빌드·sdist 재빌드·설치·editable 검증은 진행 중이다. 이번 변경은 설치 계약을 바꾸지 않는 내부 구성 정리이므로 고객용 변경 로그에 별도 항목을 추가하지 않는다.
