# editable 링크의 차등 갱신과 파일별 원자적 교체

[링크 갱신 리뷰](https://github.com/yong5eon/DefStream/pull/54#discussion_r4417252183)를 반영했다. 다른 두 프로젝트와 동일한 helper이므로 미관리 파일이 있는 디렉터리의 정리 실패도 함께 수정했다.

- `scripts/editable_view.py`의 `refresh()`에서 전체 삭제·재생성을 제거했다. 같은 원본을 가리키는 링크는 유지하고 변경된 파일은 같은 부모의 임시 디렉터리에 새 링크를 만든 뒤 `Path.replace()`로 교체한다.
- 이전 선택에서 빠진 관리 파일과 영향을 받은 파일의 bytecode만 제거한다. 빈 디렉터리만 정리하고 `.DS_Store` 등 미관리 파일로 비어 있지 않은 디렉터리는 보존한다. 다른 오류는 전파한다.
- hardlink 원본 교체 중 코어·기존 파일 보존, 미관리 파일이 있는 선택 해제, 링크 생성 실패 시 기존 파일·선택 기록 보존의 회귀 테스트 3개를 추가했다.
- 한영 Packaging 매뉴얼에 파일별 교체와 미관리 파일 보존, 전체 트리 원자성·실행 중 모듈 재로딩의 비보장 범위를 반영했다.

일반 wheel·제품 API는 변경하지 않았다. 전체 트리 트랜잭션이나 실행 중 import를 잠그는 별도 장치는 추가하지 않았다. 검증은 [작업 기록](../tasks/1793327181558.md)에 정리한다.
