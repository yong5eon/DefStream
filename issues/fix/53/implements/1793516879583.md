# 개발용 설치 코드와 테스트 숨김 경로 이동

사용자 요청에 따라 `scripts/editable_view.py`와 관련 테스트를 `.dev/scripts/`로 옮겼다. 코드와 테스트 로직은 유지하고 `setup.py`의 helper 복사·sdist 포함 목록, 배포 검사기의 필수 파일·검증 소스 복사 경로, CI 변경 감지·단위 테스트 경로를 갱신했다.

워크플로용 빌드·백엔드·배포 스크립트는 `.github/scripts/`에 유지했다. 설치된 helper 이름과 `.pth`, EXTRAS 계약은 변경하지 않았다. [검증 기록](../tasks/1793516879584.md).
