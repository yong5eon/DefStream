# 단일 editable에 맞춘 제품 패키징 테스트

새 editable 환경에서 기존 `tests/test_broker_packaging.py`를 실행해 별도 구현체 배포물 부재와 editable RECORD 형식 차이로 실패하는 것을 재현했다. 일반 wheel 전용 가정을 새 개발 설치 계약과 구분해야 했다.

`distribution_files()`는 editable에서는 파일 명세를, 일반 설치에서는 RECORD를 읽는다. 소유권 테스트는 일반 wheel의 코어·구현체 분리 검증을 유지하고 editable에서는 단일 코어의 선택 파일과 별도 배포물 부재를 검사한다. 의존성 테스트도 일반 설치의 동일 버전 구현체 연결과 editable의 선택 클라이언트 연결을 각각 검증한다.

타입 검사에서 발견한 조건부 변수의 미할당 가능성은 소유 배포물의 파일 집합을 양쪽 분기에서 명확히 정하도록 수정했다. 일반 wheel과 단일 editable에서 각각 4개 테스트를 통과했고 Pyright 오류는 0개다. 자세한 최종 검증은 [작업 기록](../tasks/1793301829546.md)에 정리했다.
