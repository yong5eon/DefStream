# EXTRAS 기반 단일 editable 설치

사용자가 요청한 명령형 선택을 위해 `scripts/build_backend.py`를 추가하고 `pyproject.toml`의 로컬 백엔드로 연결했다. PEP 660의 요구사항·메타데이터·wheel 훅마다 같은 `EXTRAS` 목록을 전달하고 기존 환경변수는 복원한다. editable에서는 남아 있는 `DEF_BUILD_TARGET`을 무시하고 코어 배포물 하나를 만든다. 일반 wheel/sdist는 기존 대상별 빌드를 유지하며 `EXTRAS` 오용을 거부한다.

`setup.py`는 editable에서 RabbitMQ/Redis 중 선택한 패키지와 외부 의존성만 포함하고 `editable-selection.json`에 목록을 기록한다. 옵션 생략은 코어만 선택하며 재실행은 누적이 아니라 교체다. 코어 선행 설치나 개발 버전의 별도 구현체 동기화가 필요하지 않다. 백엔드에서 pip를 중첩 호출하거나 대상 환경을 직접 수정하지 않는다.

`scripts/editable_view.py`는 이전 별도 구현체 배포물이 함께 있으면 명시적 오류를 낸다. 선택 링크 트리와 기존 import/API는 유지한다. `MANIFEST.in`에 백엔드와 그 의존 소스를 포함해 독립 sdist 재빌드를 유지했다.

한영 Packaging 매뉴얼에 새 명령·최초 제거 후 전환·옵션 생략·외부 라이브러리 자동 삭제 제외를 반영했다. 최소 Python 3.9에서 실행되는 타입 별칭의 union 오류는 `typing.Union`으로 수정했다. 초기 빌드·sdist·선택 교체 검증을 통과했으며 오류 입력·로컬 버전 변경을 추가한 최종 검증은 진행 중이다.
