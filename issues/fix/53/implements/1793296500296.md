# 릴리즈 테스트 디렉터리 분리

`scripts/test_release.py`를 `scripts/tests/test_release.py`로 이동했다. 테스트 내용과 운영 스크립트는 변경하지 않았다. unittest discovery를 위해 테스트 디렉터리에 `__init__.py`를 추가했다.

CI는 `python -m unittest discover -s scripts/tests -t scripts -p 'test_*.py'`를 사용한다. `scripts`를 최상위 탐색 경로로 지정하여 기존 운영 모듈 import와 mock 대상을 유지한다. 종합 작업 문서의 실행 명령도 갱신했다. [검증 결과](../tasks/1793296500299.md).
