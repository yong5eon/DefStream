# 워크플로 빌드 스크립트와 테스트 위치 정리

워크플로에서 실행하는 빌드·배포 검사·게시 준비와 테스트를 `.github/scripts/`로 옮겼다. 빌드 백엔드는 `build_distributions.py`의 구현체 목록에 의존하므로 사용자 확인 후 `build_backend.py`와 해당 테스트도 함께 옮겼다. 설치 후 실행되는 `editable_view.py`와 그 테스트는 `scripts/`에 유지했다.

- `build_distributions.py`의 저장소 루트 계산을 두 단계 상위로 변경
- `pyproject.toml`의 백엔드 경로와 `setup.py`의 sdist 포함 목록 갱신
- 배포 검사에서 새 sdist 경로를 검사하고 editable 검증용 복사본도 새 구조로 생성
- CI의 빌드·검사·게시 준비 경로, 변경 감지와 두 테스트 discovery 진입점 갱신
- 한영 Packaging 매뉴얼의 실행 명령 갱신

사용자가 지정한 Python 3.9의 `ubuntu-24.04`는 유지했다. 일반 wheel의 제품 파일과 editable 선택 계약은 변경하지 않았다. [검증 기록](../tasks/1793516005518.md).
