# 브로커 구현체 설치 격리

기본 `DefStream` 설치에는 공통 코드만 포함됩니다. RabbitMQ/Redis 구현체는 선택한 extra에 해당하는 별도 배포물로 설치되며 기존 import 경로를 유지합니다.

```shell
python -m pip install "DefStream[RabbitMQ]"
```

코어와 구현체는 동일 버전을 사용합니다. 기존 통합·별도 배포물이 있는 환경에서는 관련 배포물을 먼저 제거한 뒤 필요한 extras를 설치하거나 새 가상환경을 사용하세요. extra를 생략해 재설치해도 기존 구현체가 자동 제거되지는 않습니다.

개발 시 `pip install -e . --config-settings EXTRAS=RabbitMQ,Redis` 한 번으로 현재 로컬 소스의 코어와 선택 브로커를 갱신합니다. 환경변수나 코어 선행 설치는 필요하지 않습니다. 목록은 매번 교체되며 `pip install -e .`만 실행하면 기존 선택을 해제하고 코어만 남깁니다. 선택에서 빠진 외부 라이브러리는 자동 삭제하지 않습니다. 새 파일 추가·패키징 변경 후에는 원하는 목록으로 재실행하세요.

자세한 전환·개발 절차와 sdist의 공통 소스 포함 범위는 [설치 매뉴얼](../../../docs/Packaging.md)을 참고하세요.

editable 개발은 가상환경별로 코어와 선택 구현체만 합친 파일 트리를 제공하여 IDE에서도 일반 경로로 탐색할 수 있습니다. 직접 정션·심볼릭 링크를 만들 필요가 없습니다. 기존 분리 editable에서 전환할 때는 코어·별도 구현체 배포물을 한 번 제거한 뒤 새 명령으로 설치하고 Language Server를 재시작하세요. Windows의 하드 링크 사용 시 소스와 가상환경은 같은 볼륨에 있어야 합니다.
