## 후속 요구사항

- [완료] editable을 단일 배포물로 전환하고 PEP 660 백엔드에서 `EXTRAS`를 받는다. 일반 wheel 분리는 유지했다. 최소 Python 단위 테스트, 동일 버전 선택 교체·생략, 로컬 버전 갱신, 새 파일과 두 환경 격리를 검증하고 한영 매뉴얼·전환 안내·결과 기록을 갱신했다. 승인된 개발 환경도 기존 선택을 유지해 전환했다. 제품 패키징 테스트도 일반 wheel과 editable 양쪽에서 검증했다. [검증 결과](./tasks/1793301829546.md).
- [완료] 기존 import/API와 선택 격리를 유지하는 가상환경별 링크 트리를 구현했다. 설치·제거·두 환경 격리·정적 경로 탐색을 통과했다. 승인된 작업공간의 코어 연결을 전환했고 DefPixel의 같은 구조는 IDE 밑줄 해소를 확인했다. [검증 결과](./tasks/1793299630939.md).

변경 대상은 `setup.py`, 빌드 선언, 패키징 검사, `.github/workflows/ci.yml`, 설치 관련 README·매뉴얼이다. 요구사항과 인수 기준은 [요구사항](./REQUIREMENTS.md)을 기준으로 한다.

배포는 구현체와 코어를 같은 버전으로 준비하고 구현체를 먼저 게시한 뒤 코어를 게시하는 순서를 사용한다. 업그레이드는 과거 별도 배포물과 통합 배포물을 먼저 제거하고 새 구성으로 설치하며, 실패 시 새 배포물을 제거하고 이전 버전을 재설치한다. 이 작업에서는 게시하지 않는다.
