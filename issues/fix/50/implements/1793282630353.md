# 요청 큐 기반 RPC 응답 큐 이름 적용

`src/Broker/Implements/RabbitMQ/Queue.py`의 `Queue.call()`이 RabbitMQ에 빈 큐 이름을 전달하던 부분을 `{요청 큐}.{uuid4().hex}` 형식으로 변경했다. 응답 큐는 계속 `exclusive=True`, `auto_delete=True`로 선언되며, 생성된 큐 이름을 사용한 소비와 요청 `reply_to`, 기존 `correlation_id` 응답 일치 처리는 유지된다.

`Exchange.call()`은 별도 구현이므로 변경하지 않았다. 회귀 테스트에서 큐 RPC의 이름 형식과 옵션, `reply_to` 연결을 확인하고 Exchange RPC는 빈 이름을 계속 요청하는지 확인한다. RabbitMQ 상세 매뉴얼도 한국어·영어판을 함께 갱신했다.
