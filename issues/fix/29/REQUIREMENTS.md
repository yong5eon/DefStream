# 요구사항 명세서: 이슈 템플릿의 프로젝트 자동 등록 제거

## 출처

- 이슈: [ISSUE.md](./ISSUE.md), #29
- 원본 이슈 URL: `ISSUE.md`에 기록되어 있지 않음
- 변경 유형: 일반 변경

## 목적

이슈 템플릿에서 프로젝트 연결 설정을 제거하여, 해당 템플릿으로 새 이슈를 만들 때
프로젝트에 자동 등록되지 않도록 한다.

## 범위

### 포함

- 저장소에서 사용하는 이슈 템플릿에 프로젝트 연결 또는 자동 등록을 지정하는 설정이 있다면 제거한다.
- 이슈 템플릿으로 새 이슈를 생성해도 프로젝트가 자동으로 지정되지 않아야 한다.

### 제외

- 기존 이슈의 프로젝트 연결 상태 변경 또는 일괄 제거.
- 프로젝트 자체의 설정, 권한 또는 운영 정책 변경.
- 프로젝트 자동 등록과 무관한 이슈 템플릿 항목 및 이슈 생성 동작 변경.

## 확정 요구사항

| ID | 요구사항 |
| --- | --- |
| PROJ-01 | 이슈 템플릿은 프로젝트를 자동 지정하거나 자동 등록하도록 구성하지 않아야 한다. |
| PROJ-02 | 프로젝트 자동 등록 제거는 저장소에서 사용하는 이슈 템플릿 전체에 적용해야 한다. |
| PROJ-03 | 템플릿으로 새 이슈를 생성했을 때 프로젝트가 자동 연결되지 않아야 한다. |
| PROJ-04 | 기존에 생성된 이슈의 프로젝트 연결 상태는 변경하지 않아야 한다. |
| PROJ-05 | 프로젝트 연결과 무관한 템플릿 내용 및 이슈 생성 동작은 유지해야 한다. |

## 확인이 필요한 사항

- 이슈 원문에는 원본 이슈 URL이 포함되어 있지 않아 링크를 확인할 수 없다.
