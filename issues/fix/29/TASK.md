# 작업 내용

## 관련 요구사항

- [요구사항 명세서](./REQUIREMENTS.md)

## 작업 목적

이슈 템플릿으로 생성한 이슈가 프로젝트에 자동 등록되지 않도록 한다.

## 수행 내용

- 네 가지 GitHub 이슈 템플릿에서 `projects` 자동 등록 설정을 제거했습니다.
- 라벨, 본문 필드 및 템플릿별 안내는 변경하지 않았습니다.
- 이미 생성된 이슈의 프로젝트 연결은 변경하지 않았습니다.

## 결과

- 이후 이슈 템플릿으로 생성되는 이슈는 프로젝트에 자동 등록되지 않습니다. 필요한 경우 이슈 생성 후 프로젝트를 직접 지정해야 합니다.

## 검증

- 네 개 이슈 템플릿에서 `projects` 설정이 없음을 확인했습니다.
- 각 템플릿을 `HEAD`와 비교해 `projects` 설정 외에는 변경되지 않았음을 확인했습니다.
- `git diff --check`를 통과했습니다.
- YAML 파서 의존성이 설치되어 있지 않아 파서 기반 검증은 실행하지 않았습니다.
