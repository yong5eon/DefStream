## 진행 원칙

- 공개 API와 구현을 확인하며 문서를 작성하고, 제품 코드 변경은 하지 않는다.
- 루트 README의 기존 설명과 예제를 검토해 상세 매뉴얼에 필요한 내용을 옮기거나 확장하되, 루트 README에는 프로젝트 개요와 빠른 시작을 남긴다.
- 한국어·영어 문서는 주제, 기능, 예제와 제약을 일치시킨다.
- 루트 README의 기존 영어 서브타이틀과 슬로건은 한국어 문서에서도 번역하거나 수정하지 않는다.
- `README.setup.md`는 패키지 메타데이터로 독립 배포되는 문서이므로 외부 링크를 두지 않는다.
- 진행 중 문서 구성이 요구사항과 달라지면 이 계획과 요구사항 명세를 함께 갱신한다.
- 생명주기 훅 상세 안내와 주제별 Mermaid 다이어그램을 추가할 때 한국어·영어 쌍을 함께 갱신하고, 기존 매뉴얼의 중복 설명은 기준 문서 링크로 대체한다.

## 선행 조건과 주의사항

- 현재 작업 브랜치는 `task/36`이다. 다른 저장소나 이슈의 변경을 포함하지 않는다.
- 병합 대상 브랜치는 지정되지 않았으므로 임의로 정하거나 실제 병합에 사용하지 않는다.
- 기존 `docs/` 매뉴얼 구조에 필요한 주제 문서만 추가·갱신하고 형식적인 빈 문서는 만들지 않는다.
- `README.setup.md`의 외부 링크 금지와 루트 README의 영어 서브타이틀·슬로건 보존을 모든 편집 단계에서 확인한다.
- RabbitMQ 브로커는 준비되지 않아 Worker 메시지 처리 예제의 실제 브로커 연결 검증은 수행하지 않는다. 문서의 Python 코드 블록은 구문 검증한다.
