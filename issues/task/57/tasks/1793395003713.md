# CI 실패 원인 및 작업 범위 확인

GitHub Actions 실행 #41075016156의 `Test Python 3.9` 로그를 확인했다. `actions/setup-python`이 Ubuntu 26.04에서 Python 3.9 x64를 찾지 못해 테스트 실행 전에 중단됐다.

프로젝트는 `setup.py`와 README에서 Python 3.9 이상을 지원한다고 선언하고, CI도 3.9부터 3.14까지 테스트한다. 따라서 지원 버전 선언을 바꾸지 않고 CI 테스트 매트릭스에서 3.9에만 이전 Ubuntu 이미지를 지정하는 방향으로 범위를 정했다.

이슈 #57은 `task` 레이블이 적용되어 있고, 저장소의 현재 `master` 커밋 `5a4d155`를 기준으로 로컬 `task/57` 브랜치를 만들었다.
