# CI 매트릭스 설정 검증

저장소 루트에서 `git diff --check`를 실행해 공백 오류가 없음을 확인했다. Python의 PyYAML로 `.github/workflows/ci.yml`을 파싱하고 매트릭스 러너를 평가한 결과, Python 3.9은 `ubuntu-24.04`, Python 3.10·3.11·3.12·3.13·3.14는 `ubuntu-latest`로 매핑됐다. `changes`와 `publish` 작업의 러너는 기준 커밋과 동일함도 확인했다.

`actionlint`는 환경에서 사용할 수 없어 실행하지 않았다. 제품 코드나 테스트 코드 변경이 없는 워크플로 설정 작업이므로 로컬 Python 단위 테스트는 실행하지 않았다.

GitHub Actions에서는 아직 검증하지 못했다. `task/57`을 원격에 게시하지 않았기 때문에 수정된 워크플로가 실행되지 않았다. PR에서 Python 3.9 작업이 실제 시작하고 테스트까지 통과하는지 확인해야 한다.
