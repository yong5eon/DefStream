# Python 3.9 테스트 러너 분리

`.github/workflows/ci.yml`의 `test` 작업에서 `runs-on`이 `matrix.os`를 사용하고, 해당 값이 없는 매트릭스 항목은 기존처럼 `ubuntu-latest`를 사용하도록 변경했다. 매트릭스 `include`에는 Python 3.9에만 `ubuntu-24.04`를 지정했다. 따라서 Python 3.10 이상과 다른 CI 작업의 러너 설정은 유지된다.

Python 지원 범위, 패키지 메타데이터, 제품 및 테스트 코드는 변경하지 않았다. 로컬 정적 검증과 GitHub Actions 실행 여부는 별도 작업 기록에 남긴다.
