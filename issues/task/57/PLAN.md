# 작업 계획서

## 수행 순서

1. `test` 작업의 러너를 매트릭스 값으로 선택하도록 바꾸고, Python 3.9에만 `ubuntu-24.04`를 추가한다.
2. 워크플로 YAML과 각 Python 버전의 러너 매핑을 검토한다.
3. 변경을 검토하고, GitHub Actions 실행으로 Python 3.9 테스트가 실제 동작하는지 확인한다.
4. 구현·검증 기록과 이슈 변경 로그를 갱신한다.

## 검증 계획

- 변경 diff에서 테스트 작업만 수정되었는지 확인한다.
- YAML 파싱 또는 저장소에서 사용 가능한 워크플로 정적 검사 도구가 있으면 실행한다.
- 매트릭스 결과가 Python 3.9 → `ubuntu-24.04`, 나머지 버전 → `ubuntu-latest`인지 확인한다.
- GitHub Actions에서 Python 3.9 설치와 테스트 작업이 수행되는지 확인한다. 원격 실행이 불가능하면 미검증으로 기록하고, 브랜치를 원격에 반영한 뒤 실행할 후속 작업으로 남긴다.

## 진행 상태

- `task/57` 브랜치를 `master` 기준 커밋 `5a4d155`에서 생성했다.

- YAML 파싱, 매트릭스별 러너 매핑, 다른 CI 작업의 러너 보존을 로컬에서 검증했다.
- GitHub Actions 실제 실행은 브랜치를 원격에 반영한 뒤 확인해야 하며 아직 미실행 상태다.
