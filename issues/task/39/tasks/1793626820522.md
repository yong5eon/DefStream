# 브로커 테스트 환경 변수 이름 변경 검증

테스트 opt-in 변수와 포트 변수에서 `DEFSTREAM_` 접두사를 제거하고, CI workflow와 테스트 코드, 브로커별 로컬 실행 안내 및 요구사항 명세를 같은 이름으로 갱신했다. 현재 CI·테스트·로컬 안내·이슈 #39 범위에는 이전 이름이 남지 않았다. 이전 이슈의 구현 기록은 과거 실행 사실을 보존하기 위해 유지했다.

새 `RABBITMQ_PORT=55630`, `REDIS_PORT=56376` 값을 테스트 지원 함수가 읽는지 확인했다. 기본 포트 폴백 확인, 전체 310개 테스트(15개 건너뜀), CI YAML 파싱, `git diff --check`도 통과했다. Docker 엔진이 없어 실제 브로커에 연결하는 통합 테스트는 실행하지 못했다.
