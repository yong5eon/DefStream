# RabbitMQ 3.x·4.x 지원 범위 결정

각 RabbitMQ 메이저 버전의 최신 마이너 계열을 지원한다는 사용자 결정에 따라 `3.13.x`와 `4.4.x`를 대상으로 정했다. 공식 지원표에 따르면 RabbitMQ 4.4.x는 조사 시점의 최신 계열이고 4.3.x까지 커뮤니티 지원 중이다. 3.13.x는 공식 지원표에 없어 upstream 지원이 끝났지만, DefStream의 호환성 목표에는 포함한다.

따라서 이후 테스트는 두 마이너 계열에서 수행해야 하며, 이를 RabbitMQ 3.x와 4.x 전체 마이너 버전의 검증으로 표현하지 않는다. Redis 버전 범위는 아직 조사되지 않았으므로 Docker 리소스와 CI 변경은 보류한다.

기존 조사 근거는 [TASKS.md](../TASKS.md)에 정리했다.
