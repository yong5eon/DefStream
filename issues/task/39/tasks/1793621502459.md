# Redis Streams 최소 지원 버전 조사

Redis Streams 기본 자료구조와 consumer group 명령인 `XGROUP CREATE`, `XREADGROUP`, `XACK`는 Redis 5.0부터 사용할 수 있다. 그러나 DefStream의 [`Consumer`](../../../../src/Broker/Implements/Redis/Consumer.py)는 `reclaim_idle=60000`을 기본값으로 사용하고, 소비 루프에서 해당 값이 `None`이 아닐 때 `XAUTOCLAIM`을 실행한다. Redis 공식 명령 문서에 따르면 `XAUTOCLAIM`은 Redis 6.2부터 제공된다.

따라서 Streams 기능 자체의 도입 버전은 5.0이지만, 자동 pending 메시지 회수를 포함한 DefStream의 기본 소비 동작을 지원하는 기술적 하한은 6.2다. `reclaim_idle=None`으로 자동 회수를 끈다면 이 특정 명령의 제약은 피할 수 있지만, 기본 복구 기능이 빠지므로 동일한 동작 계약으로 보지 않는다.

저장소 [Redis.md](../../../docs/Redis.md)는 이미 Redis 6.2 이상을 요구하고 있다. GitHub Actions는 [ci.yml](../../../.github/workflows/ci.yml)에서 `redis:7.4`로 통합 테스트한다. 이에 따라 현재 근거로 정리 가능한 범위는 최소 6.2, CI 검증 버전 7.4이며, 지원 상한이나 검증 대상의 구체 계열은 아직 결정되지 않았다. Redis 5.0을 지원 대상으로 포함하려면 기본 자동 회수 동작을 변경하거나 대체할지 별도 결정이 필요하다.
