# 브로커별 메시지 테스트 import 격리 검증

GitHub Actions 실행 [#41459408504](https://github.com/yong5eon/DefStream/actions/runs/41459408504)에서 코어 job은 통과했지만 RabbitMQ·Redis 브로커 매트릭스의 24개 job은 모두 테스트 모듈 import 중 실패했다. RabbitMQ suite가 `tests.test_task_messages`를 가져오며 Redis 연결 구현을 찾았고, Redis suite는 같은 모듈에서 RabbitMQ `Reject` 정책을 찾았다. 두 브로커별 job은 해당 브로커 extra만 설치하므로 반대편 구현은 사용할 수 없다.

공통 메시지 테스트를 선택적 브로커 어댑터 없이 가져올 수 있도록 `Task`와 `Declare`를 `tests/_support_task_messages.py`로 분리했다. RabbitMQ 테스트는 필요한 `Reject` 정책을 자체 task subclass에 적용한다. `emit`/`send` 호환성 확인은 각 브로커 테스트로 옮겼고, Redis의 미지원 RPC 검증은 이미 해당 테스트에 있는 검증을 기준으로 공통 파일에서 제거했다.

## 검증

- 공통 메시지 테스트: 8개 통과
- Redis 어댑터 import를 차단한 RabbitMQ 메시지 테스트: 2개 발견, 1개 통과, 브로커 통합 테스트 1개 건너뜀
- RabbitMQ 어댑터 import를 차단한 Redis 메시지 테스트: 3개 발견, 1개 통과, 브로커 통합 테스트 2개 건너뜀
- 변경한 Python 파일 4개의 Pylance 문법 검사 통과; `git diff --check` 통과
- 통합 테스트는 opt-in 환경변수를 설정하지 않아 건너뛰었다. 브로커 서비스 동작은 이번 변경에서 다시 검증하지 않았다.

수정 후 GitHub Actions 재실행은 아직 수행하지 않았다. 현재 변경은 로컬 작업 트리에 있으며 원격 브랜치에는 반영하지 않았다.
