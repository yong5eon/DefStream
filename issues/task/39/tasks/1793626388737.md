# 패키징 테스트 수정 및 전체 테스트 검증

저장소 루트의 무시된 `DefStream.egg-info`가 설치된 distribution보다 먼저 선택되어 패키징 테스트 4개가 실패하는 것을 확인했다. 테스트에서 저장소 루트의 메타데이터를 제외하고 실제 설치된 distribution을 조회하도록 수정한 뒤, 해당 4개 테스트를 단독 실행해 통과를 확인했다.

UTF-8 출력 설정을 사용하여 프로젝트 루트 밖의 작업 디렉터리에서 프로젝트 경로를 지정한 전체 unittest discovery를 실행했다. CI와 동일하게 `tests`를 검색하고 프로젝트 루트를 top-level 경로로 지정했으며, 310개 테스트가 통과하고 15개가 건너뛰어졌다. RabbitMQ 전용 테스트는 71개 중 7개, Redis 전용 테스트는 32개 중 8개가 건너뛰어지고 나머지는 통과했다.

GitHub Actions YAML 파싱과 `git diff --check`도 통과했다. Docker 엔진에 연결할 수 없어 실제 컨테이너 기동 및 브로커 통합 테스트는 검증하지 못했다.
