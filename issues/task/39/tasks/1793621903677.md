# Redis 최소 버전 및 CI 검증 대상 결정

Redis Streams 기본 기능이 5.0부터 제공된다는 사실과 DefStream의 실제 기본 동작을 구분해 지원 하한을 결정했다. `Consumer`는 기본 `reclaim_idle=60000` 설정에서 6.2부터 제공되는 `XAUTOCLAIM`을 호출하므로, 기본 자동 pending 메시지 복구를 유지하는 지원 하한은 Redis 6.2다.

사용자 결정에 따라 Redis 지원 하한은 6.2로 확정하고, Docker/CI 통합 테스트는 최소 지원 버전인 6.2와 기존 CI 검증 버전인 7.4를 대상으로 한다. 이는 중간 버전 전체를 개별 검증한다는 뜻은 아니다. Redis 5.x는 Streams 명령은 제공하지만 기본 자동 복구 명령이 없어 이번 지원 범위에서 제외한다.

조사 근거는 [Redis 최소 버전 조사](./1793621502459.md)에 있다.
