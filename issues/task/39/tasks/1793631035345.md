# PR 리뷰 수정 검증

PR #60의 리뷰 코멘트 두 건을 확인하고 수정했다. RabbitMQ 플러그인 검사는 `rabbitmq-plugins list --enabled --minimal`의 출력에서 `grep -Fxq`로 전체 줄을 비교하도록 변경했다. 따라서 `rabbitmq_shovel_management`만 활성화되어 있을 때 `rabbitmq_shovel`이 활성화된 것으로 오인하지 않는다. `tests/test_inspector_play.py`에서는 더 이상 쓰이지 않는 `Mock` 및 `Task` import를 제거했다.

## 검증

- `tests.test_inspector_play`: 21개 통과
- Bash `grep -Fxq` 확인: `rabbitmq_shovel_management`만 있는 경우 `rabbitmq_shovel` 검색은 불일치, 정확한 `rabbitmq_shovel` 줄은 일치
- `git diff --check` 통과
- 변경 후 GitHub Actions 실행은 아직 하지 않았다.
