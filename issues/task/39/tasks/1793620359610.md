# RabbitMQ 지원 버전 및 플러그인 조사

GitHub Actions는 RabbitMQ 4.1과 Redis 7.4를 통합 테스트에 사용하고 있다. RabbitMQ 문서에서 3.12 이상은 `Subscription.timeout` 기능에 대한 조건으로만 확인했으며 전체 어댑터의 하한으로 선언되어 있지는 않다. 기존 작업 기록에는 RabbitMQ 3.13.7 검증 사례가 있다.

RabbitMQ 공식 지원 정보 기준으로 조사 시점의 커뮤니티 지원 계열은 4.3.x와 4.4.x이며, 각 지원 종료일은 2027-01-31과 2027-07-31이다. RabbitMQ 공식 플러그인 문서는 관리, Prometheus, Shovel 플러그인이 배포판에 포함되는 것으로 안내한다. 저장소에서 특정 지원 버전 범위는 확인되지 않아, 컨테이너와 CI 설정은 변경하지 않았다.

요청한 `rabbitmq_management`, `rabbitmq_prometheus`, `rabbitmq_shovel`, `rabbitmq_shovel_management` 활성화를 추가 요구사항에 기록했다. 버전 범위는 커뮤니티 지원 중인 계열 전체와 최신 계열만 검증하는 방안 중 결정이 필요하다.

조사 자료와 저장소 근거는 [TASKS.md](../TASKS.md)에 정리했다.
