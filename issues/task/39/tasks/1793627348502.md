# CI 코어·브로커 job 분리 검증

워크플로 YAML을 파싱하고 `test`, `test-rabbitmq`, `test-redis` job과 publish 의존 관계를 확인했다. 코어 job에는 브로커 테스트 활성화 변수가 없으며, YAML 매트릭스는 Python 3.9~3.14의 6개 코어 조합과 각 브로커별 12개 버전 × Python 조합을 선언한다.

코어 전용 runner로 루트 Python 테스트 모듈 18개, 총 207개 테스트가 통과했다. RabbitMQ 전용 discovery는 71개 중 7개, Redis 전용 discovery는 32개 중 8개를 건너뛰고 통과했다. Pylance 구문·진단 검사, CI YAML 파싱, `git diff --check`도 통과했다.

로컬 Docker 엔진이 없어 RabbitMQ·Redis 컨테이너를 올려 매트릭스 각 조합의 실제 호환성 테스트를 실행하지 못했다. 해당 검증은 GitHub Actions 실행 결과에서 확인해야 한다.
