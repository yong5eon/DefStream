# 브로커 통합 테스트 환경 변수 접두사 제거

RabbitMQ·Redis 테스트 설정에서 불필요한 `DEFSTREAM_` 접두사를 제거했다. 테스트 활성화 변수는 `RABBITMQ_TESTS`, `REDIS_TESTS`로, 포트 변수는 `RABBITMQ_PORT`, `REDIS_PORT`로 통일했다.

CI workflow, 테스트 환경 변수 조회, RabbitMQ·Redis 로컬 실행 안내와 이슈 요구사항을 새 이름으로 갱신했다. 기본 포트 `5672`, `6379` 동작은 유지했다. 과거 이슈의 단계별 기록은 작성 당시의 실행 내용을 보존하기 위해 변경하지 않았다.

전체 테스트와 새 포트 환경 변수 이름의 런타임 조회를 확인한 결과는 [작업 검증 기록](../tasks/1793626820522.md)에 정리했다.
