# 코어·브로커 테스트 분리

코어 테스트를 `tests/` 루트에 유지하고 RabbitMQ·Redis 전용 테스트를 각각 `tests/rabbitmq/`, `tests/redis/`로 옮겼다. Inspector 통합 테스트, 메시지·명세 RPC 테스트와 브로커별 우선순위 테스트를 각 책임 위치로 분리하고, 공통 테스트 픽스처는 `tests/`에 유지했다.

`tests/__init__.py`를 추가하고 지원 모듈과 공유 테스트 픽스처 import를 `tests.*`로 변경했다. 전체 탐색은 `python -m unittest discover -s tests -t .`를 사용해 하위 테스트를 패키지 이름으로 불러오며, `tests/redis` 디렉터리가 외부 Redis 클라이언트 import를 가리는 문제를 피한다. CI의 설치 패키지 테스트는 작업 디렉터리를 저장소 밖으로 이동하므로 `-t "$GITHUB_WORKSPACE"`도 지정해 같은 패키지 import 규칙을 유지한다.

테스트 파일 이동으로 바뀐 기준 위치에 맞춰 RabbitMQ·Redis 로그 테스트의 샘플 소스 경로를 프로젝트 루트 기준으로 수정했다. 제품 런타임과 공개 API 동작은 변경하지 않았다. 테스트 결과는 [검증 작업 기록](../tasks/1793625269565.md)에 정리했다.
