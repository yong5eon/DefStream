# 브로커별 메시지 테스트 의존성 분리

RabbitMQ·Redis 전용 테스트가 공통 `tests/test_task_messages.py`를 import하면서 선택 설치되는 두 어댑터를 모두 로드하던 구조를 분리했다. `tests/_support_task_messages.py`에는 core `Run`, `WorkerSetup`만 사용하는 공통 `Task`와 `Declare`를 두었다. RabbitMQ 테스트는 공통 task의 subclass에만 RabbitMQ `Reject` 정책을 적용하므로 Redis 전용 설치는 RabbitMQ 패키지를 요구하지 않는다.

브로커 connection의 `emit` 및 `send` 별칭 검증을 각 브로커 테스트로 옮겨 해당 어댑터만 설치한 job에서 확인하게 했다. Redis의 미지원 RPC 검증도 Redis 전용 테스트에만 남기고, 공통 core 메시지 테스트에서 Redis 어댑터 import를 제거했다. 공개 API와 제품 동작은 변경하지 않았다.

구체적인 Actions 실패 원인과 import 격리 검증 결과는 [작업 기록](../tasks/1793629199998.md)에 정리했다.
