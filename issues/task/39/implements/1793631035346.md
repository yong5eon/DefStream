# PR 리뷰 지적 수정

RabbitMQ CI의 플러그인 검증이 부분 문자열 비교를 사용해 `rabbitmq_shovel_management` 이름만 있어도 `rabbitmq_shovel`이 존재한다고 판단할 수 있었다. `--minimal` 출력에 대해 `grep -Fxq`를 사용해 플러그인 이름 전체가 한 줄로 정확히 일치하는지 검사하도록 수정했다.

또한 Inspector Play 테스트에서 helper 모듈로 이동한 뒤 더 이상 사용하지 않는 `Mock`, `Task` import를 제거했다. 제품 런타임 동작이나 공개 API는 변경하지 않았다. 검증 결과는 [작업 기록](../tasks/1793631035345.md)에 정리했다.
