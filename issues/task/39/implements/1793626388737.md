# 패키징 테스트의 메타데이터 선택 수정

전체 테스트에서 발생한 패키징 테스트 실패는 설치 패키지 자체가 아니라 저장소 루트의 무시된 `DefStream.egg-info`를 `importlib.metadata`가 먼저 선택해 발생했다. 테스트가 프로젝트 루트를 `sys.path`에 포함하면 이 로컬 메타데이터가 가상 환경에 설치된 editable distribution을 가렸다.

`tests/test_broker_packaging.py`에 설치된 distribution을 검색하는 함수를 추가했다. 저장소 루트 자체를 메타데이터 위치로 반환하는 항목은 제외하고, 설치된 distribution의 파일 목록·선택 정보·의존성을 검사한다. 실제 설치 위치가 저장소 내부의 가상 환경일 수 있으므로 저장소 루트와 정확히 같은 위치만 제외한다.

제품 동작과 패키징 구성은 변경하지 않았다. 전체 및 브로커별 테스트 검증 결과는 [후속 검증 기록](../tasks/1793626388737.md)에 정리했다.
