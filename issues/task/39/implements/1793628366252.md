# RabbitMQ 4 테스트 큐 선언 호환성 수정

Docker 기반 RabbitMQ 4.4 통합 테스트에서 네 개의 오류를 재현했다. 테스트가 `durable=False`, `exclusive=False`인 transient non-exclusive 큐를 선언했고, RabbitMQ 4.4에서는 해당 feature가 기본 비활성화되어 선언이 거부됐다.

제품의 `Connection.create_queue()` 기본값은 `durable=True`다. `test_rabbitmq_integration.py`와 `test_rabbitmq_rpc_integration.py`의 테스트 준비 큐도 `durable=True`로 명시해 실제 제품 선언과 일치시켰다. `x-expires` 설정은 그대로 유지해 테스트 큐가 비활성 상태에서 만료되는 동작은 보존했다.

수정 후 RabbitMQ 4.4의 전체 71개 테스트가 통과했다. Python 3.9·3.10·3.12·3.14 각 버전에서도 해당 suite가 통과했다. 전체 브로커 조합 결과는 [Docker 통합 테스트 기록](../tasks/1793628366252.md)에 정리했다.
