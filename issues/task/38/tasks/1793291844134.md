# 적용 파일 동일성 확인과 스크립트 테스트 검증

## 원본 동일성 확인

복사한 6개 파일 모두 DefPixel 원본과 SHA-256 해시가 일치함을 확인했다. 대상은 [구현 기록](../implements/1793291844133.md)의 파일 목록과 같다.

## 스크립트 테스트

저장소 루트에서 Node.js 24(v24.11.1)로 실행했다.

```shell
node --test .github/scripts/tests/create-pr-from-issue.test.mjs .github/scripts/tests/create-issues-from-reviews.test.mjs
```

결과: 77개 테스트 전부 통과(pass 77, fail 0). 테스트는 네트워크 호출 없이 목(mock)으로 동작한다.

## 저장소 설정 확인

GitHub API(`gh api repos/{owner}/{repo}/actions/variables`, `.../actions/secrets`)로 이 저장소에 Actions 변수 `PR_APP_CLIENT_ID`와 Secret `PR_APP_PRIVATE_KEY`가 이미 등록되어 있음을 확인했다. 값의 유효성과 GitHub App의 저장소 설치 여부는 API로 확인할 수 없어 실제 워크플로 실행으로 확인해야 한다.

## 실행하지 못한 검증과 사유

- 실제 push·리뷰 제출에 따른 워크플로 끝단 동작은 기본 브랜치 병합(리뷰 이슈 등록)과 실제 이벤트 발생 이후에만 가능하다. 시험 절차는 [GitHub 사전 설정 및 시험 안내](../docs/CopilotReviewIssuesSetup.md)를 따른다.
- DefPixel에서는 동일 파일로 실제 PR 생성과 리뷰 이슈 등록이 동작함을 사전 검증했다([DefPixel#12](https://github.com/yong5eon/DefPixel/issues/12)). 이 결과를 이 저장소의 끝단 검증으로 대체하지 않는다.
