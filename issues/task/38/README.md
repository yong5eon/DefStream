## 이슈 원문

## 목적

Copilot이 PR 코드 리뷰에서 발견한 후속 조치 사항을 놓치지 않도록, 리뷰 결과를 GitHub 이슈로 자동 등록하는 GitHub Actions 워크플로를 추가합니다. 이 이슈는 추후 구현을 위한 작업 등록이며, 현재 워크플로가 구현되어 있다는 의미는 아닙니다.

## 요구사항

- 해당 저장소의 PR에 게시되는 Copilot 코드 리뷰를 대상으로 합니다. 일반 사용자의 리뷰나 무관한 봇 댓글은 대상에서 제외합니다.
- 실제 Copilot 리뷰 이벤트와 작성자 식별 정보를 확인하고, 후속 조치가 필요한 리뷰 지적 사항을 자동으로 이슈로 등록합니다.
- 자동 생성되는 이슈의 제목과 설명은 한국어로 작성합니다. 리뷰 원문이 영어여도 핵심 문제와 필요한 조치를 한국어로 설명하며, 코드 식별자와 외부 API 이름은 원문을 유지합니다.
- 생성된 이슈에서 원본 PR, 리뷰 또는 코멘트, 대상 파일과 코드 위치를 확인할 수 있도록 출처 링크와 문제 설명을 포함합니다. 리뷰 원문을 보존하는 경우 한국어 설명과 구분합니다.
- 같은 리뷰 지적 사항에 대해 이벤트 재전달이나 워크플로 재실행으로 중복 이슈가 생성되지 않도록 합니다.
- 이슈 생성에 필요한 최소 권한을 사용하고, PR 코드나 리뷰 본문을 실행하지 않습니다. 등록 실패는 워크플로 결과에서 명확히 확인할 수 있어야 합니다.

## 구현 시 확인할 사항

- 리뷰 본문과 코드 줄별 코멘트 중 실제 Copilot 리뷰에서 처리할 이벤트 및 이슈 생성 단위
- 후속 조치 대상 지적 사항과 단순 요약·긍정적인 의견의 구분 방법
- 한국어 작성 방식과 필요한 인증·설정 및 비용 여부

## 완료 기준

- [ ] Copilot PR 리뷰의 조치 대상 지적 사항으로부터 이슈가 자동 생성됨
- [ ] 자동 생성되는 이슈 제목과 설명이 한국어이며 원본 리뷰 출처를 추적할 수 있음
- [ ] 일반 사용자 리뷰와 대상이 아닌 댓글은 이슈로 생성되지 않음
- [ ] 동일 리뷰 이벤트를 재처리해도 중복 이슈가 생성되지 않음
- [ ] 필요한 권한, 설정, 동작 범위와 실패 확인 방법을 문서화함
- [ ] 실제 Copilot 리뷰 또는 확인된 이벤트 데이터로 동작을 검증함
