# 변경 로그

## 저장소 자동화 추가

- 이슈 작업 브랜치(`bug/{번호}`, `fix/{번호}`, `feature/{번호}`, `task/{번호}`)에 push하면 이슈 기록 문서를 바탕으로 기본 브랜치 대상 PR이 자동 생성됩니다. 원본 이슈의 레이블·담당자·마일스톤이 PR에 적용되고, PR 병합 시 연결된 이슈가 자동으로 닫힙니다. 같은 브랜치의 열린 PR이 있으면 중복 생성하지 않습니다.
- PR에 리뷰가 제출되면 미해결 리뷰 스레드의 조치가 필요한 지적 사항이 한국어 이슈로 자동 등록됩니다. 생성된 이슈에서 원본 PR·리뷰 코멘트·코드 위치를 추적할 수 있으며, 작업 브랜치에 대응하는 부모 이슈에 연결됩니다.
- 사용을 위해 저장소 Actions 변수 `PR_APP_CLIENT_ID`와 Secret `PR_APP_PRIVATE_KEY` 등록, GitHub App 설치가 필요합니다. 설정과 시험 방법은 [GitHub 사전 설정 및 시험 안내](./docs/CopilotReviewIssuesSetup.md)를 참고하세요.
- 재실행이나 반복 리뷰 제출로 생긴 중복 이슈는 자동으로 정리되지 않으므로 생성 결과를 확인하고 정리해야 합니다.
- 라이브러리 사용자에게 영향을 주는 코드 변경은 없습니다.
