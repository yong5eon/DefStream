# DefPixel에서 검증된 PR·리뷰 자동화 워크플로 적용

DefPixel 저장소에서 사전 검증된 자동화 파일 6개를 수정 없이 같은 경로로 복사했다.

- `.github/workflows/create-pr-from-issue.yml`: 이슈 브랜치(`bug/**`, `fix/**`, `feature/**`, `task/**`) push 시 이슈 기록 문서와 PR 템플릿으로 기본 브랜치 대상 PR을 자동 생성. GitHub App 토큰(`contents: read`, `issues: write`, `pull-requests: write`)을 사용하고 원본 이슈의 레이블·담당자·마일스톤을 PR에 동기화하며 Development에 이슈를 연결한다.
- `.github/workflows/create-issues-from-reviews.yml`: PR 리뷰 제출(`pull_request_review.submitted`) 시 테스트 job을 먼저 통과한 뒤, 미해결 리뷰 스레드의 조치 대상 최초 코멘트를 Copilot CLI로 분석하여 한국어 이슈로 등록. GitHub App 토큰(`issues: write`, `pull-requests: read`)과 Copilot 인증용 기본 `GITHUB_TOKEN`을 분리해 사용한다.
- `.github/scripts/create-pr-from-issue.mjs`, `.github/scripts/create-issues-from-reviews.mjs`: 위 워크플로가 실행하는 스크립트. 저장소 정보는 `GITHUB_REPOSITORY` 등 환경 변수로 받으므로 저장소별 수정이 필요 없다.
- `.github/scripts/tests/create-pr-from-issue.test.mjs`, `.github/scripts/tests/create-issues-from-reviews.test.mjs`: `node --test`용 단위 테스트. 목(mock) 데이터에 DefPixel 예시 URL이 있으나 네트워크 호출 없이 동작하며 결과에 영향이 없다.

스크립트·워크플로 본문은 변경하지 않았고, 기존 `ci.yml`과 이슈·PR 템플릿은 건드리지 않았다. 원본과의 동일성·테스트 결과는 [검증 기록](../tasks/1793291844134.md)을 참조한다.
