# 공통 지침 및 AGENTS 진입점 추가

`AGENTS.md`를 추가해 에이전트가 공통 지침과 DefStream의 적용 가능한 프로젝트별 지침을 먼저 읽고, 요청 범위와 승인 경계를 지키도록 안내했다. 공통 지침 다섯 파일을 원본 `Instructions` 커밋 기준으로 `instructions/common/`에 복사했다. `GIT.COMMIT.MESSAGE.instructions.md`는 제외했다. CI가 요구하는 `issues/task/67/CHANGELOG.md`도 작성했다.

파일 경로와 원본 내용 일치 여부, changelog의 정규 파일·비어 있지 않음 조건을 확인했다. 제품 코드나 런타임 동작은 변경하지 않았다.
