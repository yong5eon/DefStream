# 공통 지침과 PR 자동화 연동

csvd2c의 공통 지침을 `.instructions.assistant/`에 복사하고 `.agent/`를 대체했다. `INSTRUCTIONS.instructions.md`와 `AGENTS.md`의 프로젝트 이름을 조정하고 프로젝트 전용 `.instructions/`는 유지했다.

PR 생성 워크플로와 스크립트를 csvd2c 버전으로 갱신했다. 이슈 브랜치는 `IR.md`를 사용하고 에이전트 브랜치는 열린 PR의 변경 파일에서 이슈 문서 하나를 찾아 제목과 본문을 갱신한다. 프로젝트 CI의 릴리즈 노트 수집 단계는 PR의 마지막 `Changes:` 경로를 우선하고 없으면 기존 경로를 사용한다.

관련 테스트도 복사했다. 검증 결과는 [작업 기록](../tasks/1794072954261.md), 판단은 [근거 기록](../context/1794072954261.md)에 기록한다.
