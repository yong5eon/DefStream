# csvd2c 지침과 자동화 적용 판단

## 상황과 근거

사용자는 csvd2c의 지침과 PR 자동화를 세 프로젝트에 적용하고, 기존 이슈와 브랜치에서 이어서 작업·기록하도록 지정했다. [이슈 원문](../README.md)은 커밋 메시지 지침을 제외하지만 후속 요청은 csvd2c의 지침을 적용하도록 범위를 변경한다.

현재 `task/67`의 PR #68은 열려 있고 병합 대상은 `master`다. 공통 지침의 실제 위치는 `.agent/`이며 기존 기록에 적힌 이전 경로와 다르다. PR 생성기는 이슈 브랜치명으로 경로를 유도하고 릴리즈 수집도 같은 방식이다.

## 결정과 영향

프로젝트별 지침을 보존하면서 csvd2c 지침을 `.instructions.assistant/`에 적용한다. PR 생성기와 테스트는 csvd2c의 현재 버전을 사용하고 프로젝트별 CI는 릴리즈 노트 수집 단계만 변경한다. 에이전트 브랜치의 워크플로와 스크립트도 GitHub App 권한을 사용하게 되므로 해당 브랜치의 신뢰가 필요하다.

PR 생성 전 푸시는 건너뛰며 이후 푸시가 필요하다. 에이전트가 본문을 나중에 수정하면 자동화 결과를 덮어쓸 수 있다. 실제 GitHub Actions 실행은 아직 확인하지 않았다.
