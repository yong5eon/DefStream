# 공통 지침 제공 방식 결정

## 상황과 목표

GitHub에 할당된 에이전트가 DefStream 저장소만 확인할 수 있어 로컬의 공통 지침 링크를 이용하지 못할 수 있다. 에이전트가 지침을 실제로 읽고 PR의 필수 changelog를 누락하지 않게 하는 것이 목표다.

## 근거와 해석

- 프로젝트별 지침은 `instructions/`에서 Git으로 추적된다.
- 공통 원본은 `yong5eon/Instructions`의 커밋 `8706862712c800682f38af3c86e74f768345d811`이다.
- `.github/workflows/ci.yml`은 PR 브랜치명을 사용해 `issues/{branch}/CHANGELOG.md`를 요구한다. `task/67`에서는 `issues/task/67/CHANGELOG.md`가 필요하다.

## 결정과 영향

공통 지침 사본을 저장소 안에 고정 커밋 기준으로 두고 루트 `AGENTS.md`에서 명시적으로 읽도록 했다. 외부 clone은 네트워크·권한에 의존하므로 선택하지 않았다. 이후 원본 변경 시 사본이 자동 갱신되지는 않으며, 원본 커밋을 비교해 동기화해야 한다.

## 결과와 불확실성

AGENTS와 다섯 지침 사본 및 필수 changelog를 작성했다. 실제 GitHub Codex·Copilot 세션에서 로드 여부를 확인하는 작업은 이 로컬 변경만으로 수행하지 않았다.
