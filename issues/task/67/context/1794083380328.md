# PR 리뷰 후속 수정 판단

## 상황과 근거

사용자가 세 PR의 리뷰 분석 후 두 가지 수정만 승인했다. CI는 마지막 줄에서 들여쓰기를 제거한 뒤 `Changes:` 경로를 검사해 중첩 항목을 사용할 수 있다. PR 생성기는 변경 로그를 읽을 때 링크를 따라가지만 릴리즈 수집은 Git의 일반 파일만 허용한다.

## 결정과 영향

들여쓴 목록 마커를 감지한 경우 원래 들여쓰기를 유지해 형식 오류로 처리한다. 기존 네 칸·탭 들여쓰기 코드 블록은 마커가 없는 것으로 처리하는 동작을 보존한다. PR 생성기는 읽은 변경 로그의 링크 자체를 확인해 일반 파일만 허용한다. 사용자의 결정에 따라 3,000개 파일 제한과 App 권한 구조는 변경하지 않는다. 구현과 검증은 아직 진행 전이다.
