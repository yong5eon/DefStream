# 이슈·브랜치·지침 및 CI 확인

GitHub 이슈 [#67](https://github.com/yong5eon/DefStream/issues/67)을 생성하고 `task` 레이블 적용을 재조회해 확인했다. 저장소가 깨끗하고 현재 브랜치가 `master`인 것을 확인한 뒤 `task/67`을 만들었다.

프로젝트별 지침이 `instructions/`에 있고, 공통 원본이 `yong5eon/Instructions`임을 확인했다. `.github/workflows/ci.yml`의 릴리즈 노트 단계가 PR head branch에서 `issues/{branch}/CHANGELOG.md`를 읽는 것을 확인했다. 따라서 `task/67`에 대응하는 필수 경로는 `issues/task/67/CHANGELOG.md`다.
