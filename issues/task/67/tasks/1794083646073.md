# 수정 전 재현과 검증

DefPixel의 공통 코드에서 수정 전 릴리즈 수집 테스트의 들여쓴 항목 세 사례가 잘못 경로 선택으로 진행했다. Windows에서는 심볼릭 링크 생성이 권한 오류로 차단되어 Linux 환경을 사용했고, 수정 전 일반 파일을 가리키는 링크가 PR 생성 요청까지 진행하는 것을 확인했다. [판단 근거](../context/1794083646073.md)

DefPixel에서 Linux Node 24로 `node --test .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 74개가 통과했고, `python -S -B -m unittest discover -s .github/scripts/tests -p test_release_notes.py -q`로 7개가 통과했다. 세 저장소의 공통 코드·테스트와 릴리즈 수집 단계가 일치해 나머지 저장소에서 같은 테스트를 반복하지 않았다.

상세 매뉴얼과 루트 README는 제품 사용법을 다루므로 개발 자동화 변경에 따른 수정이 필요하지 않다. 이번 수정의 실제 GitHub Actions 실행은 검증하지 않았다.
