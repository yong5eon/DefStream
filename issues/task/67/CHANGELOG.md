# 개발 자동화 변경

DefStream의 런타임 동작, 공개 API와 설치 방법은 변경되지 않습니다. GitHub 에이전트가 저장소의 공통·프로젝트 지침을 확인하고 이슈별 변경 로그를 빠뜨리지 않도록 안내를 추가했습니다.

- 공통 에이전트 지침을 `.instructions.assistant/`에서 확인합니다.
- 이슈 PR의 제목과 본문은 `IR.md`를 사용합니다. 기존 이슈 브랜치에도 이 문서가 필요합니다.
- `copilot/**`, `codex/**`의 열린 PR은 변경 파일에서 이슈 `IR.md` 하나를 찾아 갱신합니다.
- PR 본문의 마지막 `Changes:` 항목으로 이슈·비이슈 변경 로그를 지정할 수 있습니다.
- `Changes:` 항목은 들여쓰지 않고 작성해야 합니다. 앞에 공백이 1~3칸 있으면 오류가 발생합니다.
- PR 자동화는 변경 로그로 심볼릭 링크 대신 비어 있지 않은 일반 파일을 요구합니다.

에이전트의 기존 브랜치에는 변경된 워크플로가 포함되어야 합니다. 이슈 문서가 없거나 여러 개면 갱신이 실패하며, 에이전트의 이후 PR 본문 수정은 자동화 결과를 덮어쓸 수 있습니다.

마지막 줄이 네 칸 이상 또는 탭으로 들여쓰기된 경우 기존처럼 브랜치 경로를 사용합니다. 이때 중첩 목록과 코드 예시는 구분하지 않습니다.
