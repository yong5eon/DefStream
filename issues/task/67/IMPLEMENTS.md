# 구현 결과

## 초기 구현

루트 `AGENTS.md`를 추가해 GitHub Codex·Copilot 에이전트가 공통 작업 원칙과 DefStream의 프로젝트 지침을 확인하도록 했다. 공통 지침 다섯 파일은 원본 커밋 `8706862712c800682f38af3c86e74f768345d811`의 내용 그대로 `instructions/common/`에 제공했다. 로컬 링크나 외부 저장소 접근에 의존하지 않게 한 이유는 GitHub 작업환경에서 저장소 밖 자료를 보장할 수 없기 때문이다. 커밋 메시지 작성 지침은 요청 범위에서 제외했다.

에이전트 지침에 CI가 읽는 `issues/task/67/CHANGELOG.md`의 존재·비어 있지 않음 확인을 추가했다. CI 경로는 PR 브랜치명에서 유도되므로 `task/67` 브랜치에서 해당 위치가 필수다.

## 후속 변경

공통 지침을 `.instructions.assistant/`로 옮겨 csvd2c의 지침에 맞추고 프로젝트별 지침을 보존했다. PR은 `IR.md`를 사용하며 에이전트 브랜치는 열린 PR의 변경 파일에서 이슈 문서를 찾는다. 릴리즈 노트는 PR의 `Changes:` 경로를 우선하고 없으면 기존 경로를 사용한다.
