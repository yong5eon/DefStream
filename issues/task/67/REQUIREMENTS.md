# 요구사항

## 분석

- GitHub 에이전트는 대상 저장소를 기준으로 작업하므로 로컬 개발환경의 공통 지침 링크에 의존할 수 없다.
- 저장소의 프로젝트별 지침은 추적되지만 공통 지침은 각 저장소의 일반 작업 파일로 제공되지 않았다.
- `.github/workflows/ci.yml`은 PR 브랜치명을 사용해 `issues/{branch}/CHANGELOG.md`를 찾고, 파일이 없거나 비어 있으면 실패한다.
- 따라서 AGENTS 진입 문서와 추적 가능한 공통 지침 사본을 추가하고, CI가 읽는 이슈별 변경 로그를 작성해야 한다.

## 확정 요구사항

- 루트 `AGENTS.md`는 작업 전 공통 지침과 적용 가능한 DefStream 지침을 읽도록 한다.
- 공통 지침 사본은 `instructions/common/`에 두고 원본 `yong5eon/Instructions`의 커밋 `8706862712c800682f38af3c86e74f768345d811`에서 복사한다. 커밋 메시지 전용 지침은 제외한다.
- `AGENTS.md`는 승인 범위, 이슈 작업, 작업 판단 기록, 검증과 `issues/task/67/CHANGELOG.md` 확인을 안내한다.
- 제품 소스·공개 API 변경은 제외한다.

## 인수 기준

- AGENTS에서 링크한 다섯 공통 지침 파일과 프로젝트별 지침 파일이 실제 경로에 존재한다.
- 공통 파일이 지정한 원본 커밋과 동일하며 커밋 메시지 전용 지침은 포함하지 않는다.
- 이슈별 `CHANGELOG.md`가 일반 파일이며 비어 있지 않다.
- CI가 기대하는 경로가 브랜치 `task/67`의 `issues/task/67/CHANGELOG.md`와 일치한다.
