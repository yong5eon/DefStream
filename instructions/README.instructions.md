# DefStream 루트 README 작성 지침

## 문서별 역할

- `README.md`는 한국어로 DefStream을 소개하고 핵심 사용 정보를 안내한다.
- `README.en.md`는 `README.md`와 주요 기능, 설치 및 빠른 시작 범위를 맞춘 영어 문서다. 공개 기능이나 사용법을 변경하면 두 문서를 함께 갱신한다.
- `README.setup.md`는 패키지 저장소에서 독립적으로 읽을 수 있는 간결한 영어 설명이다. 프로젝트 소개, Python 요구 사항, 설치 방법과 최소 빠른 시작을 포함한다.
- 이 지침은 루트의 세 README에만 적용한다. 상세 사용 설명과 주제별 매뉴얼은 `instructions/DOCS.instructions.md`의 지침에 따라 `docs/`에 작성한다.

## README에 포함할 정보

- 프로젝트의 목적과 핵심 기능을 실제 구현에 근거해 간결하게 설명한다.
- 지원 Python 버전, 설치 방법과 선택 가능한 RabbitMQ·Redis extra를 정확히 안내한다.
- 처음 사용할 수 있는 최소 빠른 시작 예제를 포함하고, 필요한 브로커 실행 등 전제 조건을 설명한다.
- 루트의 `README.md`와 `README.en.md`에서 상세 매뉴얼의 진입점인 `docs/README.md`로 연결한다. 링크 문구는 문서 언어에 맞추고 쉽게 찾을 수 있게 배치한다.
- 루트 README에는 상세 매뉴얼 전체를 복사하지 않는다. 자세한 API, 설정, 브로커별 운영법과 추가 사례는 `docs/`로 안내한다.

## 버전 및 변경 이력

- `README.md`와 `README.en.md`에서 최신 릴리즈와 전체 변경 이력을 확인할 수 있도록 DefStream 릴리즈 페이지로 연결한다.
- 릴리즈마다 수동 갱신이 필요한 버전 번호를 문서에 중복 기록하지 않는다. 버전을 표시해야 하면 릴리즈 기준 정보와 자동으로 동기화되는 방법을 사용한다.
- 주요 변경 사항을 루트 README에 소개할 필요가 있으면 핵심만 요약하고, 전체 이력은 릴리즈 페이지를 기준으로 한다.
- `README.setup.md`는 외부 URL이나 외부 웹 페이지 링크를 포함하지 않는다. 따라서 릴리즈 페이지 링크도 넣지 않는다.

## 정확성 및 표현

- 공개 기능, 지원 범위, 동작과 제약은 DefStream의 현재 코드와 설정에 맞게 작성한다. 확인하지 않은 보장이나 기능을 추가하지 않는다.
- 코드 예제와 import 경로는 현재 공개 API를 사용하고, 설치 명령과 extra 이름은 패키지 설정과 일치시킨다.
- RabbitMQ와 Redis Streams는 선택 의존성임을 분명히 하고, 실제 브로커가 필요한 예제에는 전제 조건을 표시한다.
- README의 문서 언어에 맞춰 자연스럽게 작성하고, 기술 식별자와 공개 API 이름은 원문을 유지한다.
- 기존 공통 마크다운 지침을 따른다. `README.setup.md`에 대해서는 외부 링크 금지를 우선 적용한다.
